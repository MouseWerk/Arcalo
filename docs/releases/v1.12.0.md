Arcalo 1.12.0

## Improved

- Microsoft Store build: Arcalo can be installed from the Microsoft Store as a package Microsoft signs, so Windows no longer warns about an unknown publisher. The Store version updates through the Store (Settings → Über → Updates says so and opens the Store); it has no own update check, rollback or portable mode, starts with Windows through its startup task (Windows Settings → Apps → Autostart) and keeps its data in the same folder as the installer version (docs/release/microsoft-store.md).
- Pasting Markdown copied as plain text (from a `.md` file, a code editor or an AI chat) now shows it formatted: headings, lists, tasks, tables, bold and links instead of literal `#`, `-` and `**`. „Als Text einfügen“ turns it back into the plain text.
- Links to a section now go there: `[[Seite#Abschnitt]]` and `[[Seite#^id]]` open the page scrolled to that heading or block (briefly highlighted), and same-page links `[[#Abschnitt]]` work as in Obsidian.
- Alt+Enter follows the link at the caret (Ctrl+Alt+Enter in a new tab), so links can be opened without the mouse.
- Find in page brings the first match into view while you type.
- The paragraph style in the editor toolbar shows its full name („Überschrift 1“ instead of „Übersch…“) in narrow panes.
- `/zeit` understands time spans: `/zeit NP-8801/1020 9:00-10:30 Abstimmung` books 1,5 h from 9:00 (also `9.00–10.30` and over midnight, `22:00-01:00`). On a page linked to a Vorgang the span can come first, like a duration.
- `/zeit` lines starting with any duration the booking understands (`1h30m`, `90mins`, `2std.`) are recognized as such in the editor, and without a reference the error now says the Netzplan is missing instead of „Ungültige Dauer“.
- A `/zeit` booking for an earlier day without start time now begins after that day's last booking instead of all at 08:00, so the Kalender shows them one after another.
- New time entries and the timer start with the Netzplan's default Leistungsart from Settings → Zeiterfassung (it was always DEV).
- The duration field of a time entry accepts `1h 30m`, `90 min` and `1,5 Std.` as well.
- In a narrow pane the timesheet's week navigation gets its own row, so the actions stay together.
- Without a connected AI, the inline AI bar (Ctrl+J), „Besprechung zusammenfassen“ and the assistant show „Keine KI verbunden“ with a „KI einrichten“ button that opens Settings → KI & Modelle, instead of actions that fail; „Tags mit KI vorschlagen“ only appears once a provider can be asked.
- Failed requests in the inline AI bar, the meeting summary and the day review summary now say what went wrong and how to fix it (as the assistant does), with the server's message under „Details“ and „Verbindung prüfen“; that button always opens the AI section of the settings.
- A provider whose key the server rejects shows „Zugang abgelehnt – Schlüssel prüfen“ in Settings → KI & Modelle instead of „Keine Verbindung“.
- Settings → Sprachnotizen has a title and a short introduction like the other sections.
- Jira errors say what happened and how to fix it: a certificate the computer does not trust (a company certificate authority) points to Settings → Netzwerk (add the root certificate or trust the server), an unknown server name to a typo or the VPN, a refusing proxy to the proxy profile, a proxy asking for a login (407) to its user and password, a gateway or server error (5xx) to trying again in a few minutes; a refused login names the token of the site's kind (API token or personal access token) and where to create a new one.
- A saved JQL search that Jira rejects (a typo, a field that does not exist) shows its error under the search in Settings → Jira until a sync runs it again, instead of failing silently.
- Settings → Jira takes intranet addresses without a dot (`https://jira`, `http://jira:8080`), and an address copied from the browser (`…/browse/PROJ-123`, a board link) keeps only the site's base.
- A calendar subscription that returns a web page (a login or sharing page instead of the calendar) says to copy the calendar's ICS link; 401, 403, 404 and server errors of a subscription say how to fix them.
- The Issues page's warning for a failing Jira site dates the shown issues by that site's last good sync and opens Settings → Jira.
- Settings → Jira: JQL and site addresses show `!=` and `://` as typed (no font ligatures), the saved searches block has room below its add row, the sync row says „Alle Jira-Sites jetzt abgleichen“; dialogs leave room between a field's hint and the next field.
- Settings → Über → „Lizenzen“ shows Arcalo's license text and a searchable list of the open-source libraries it ships, with version and license.
- The settings menu is a single Tab stop: the arrow keys, Home and End move through it, Tab goes on to the open section. Tab also leaves a shortcut recorder in Settings → Tastatur.
- Settings → Sprache & Format says that the language applies to the whole app and names the system's language.
- On a computer without Windows Hello or Touch ID and with an unencrypted database, setting the app lock PIN warns that a forgotten PIN cannot be reset in Arcalo, and „PIN vergessen?“ on the lock screen shows the command that removes the lock by hand.
- Settings → Verwaltung can also reset Ordner & Ablage, Jira, Briefing and Sprachnotizen; exported settings are named `arcalo-einstellungen-<date>.json` (`arcalo-settings-…` in English).
- A note that cannot be saved (full disk, read-only folder) shows „Nicht gespeichert – Arcalo versucht es weiter“ at its top until a save works, not only a toast that disappears.
- Database errors say what to do: a full disk asks to free some space, a read-only database to check the folder's permissions, a locked one names virus scanners and sync programs, a damaged one points to Settings → Sicherung.
- A save that removes most of a page (select all and type, a paste over everything) keeps the text before it as a version, also within the 10 minutes between versions.
- The command palette finds titles with umlauts and ß however they are typed: „ubersicht“ and „uebersicht“ both find „Übersicht“, „strasse“ finds „Straße“.
- The page tree works from the keyboard like a file manager: Shift+arrows select a range (and shrink it again), Ctrl+A selects all visible pages, F2 renames, Entf moves the page or all selected pages to the trash (several pages with one confirmation and one „Rückgängig“). The selection's menu offers „N Seiten löschen“.
- Toasts stay open while the pointer is on them or one of their buttons has the focus, so „Rückgängig“ can always be reached.
- Finishing a task in Aufgaben under „Offen“ shows „Aufgabe erledigt“ with „Rückgängig“.
- Tabs in a narrow pane keep a readable title: they no longer shrink to one letter, the close button of an inactive tab appears over the title's end on hover.
- Screen readers: context menus move the focus onto their items (and back to where it was when they close), checked entries say so; the command palette announces the chosen result; the tab bar is a tab list with named tabs, Home and End; the sidebar's pane switcher and every segmented choice are one Tab stop with arrow keys; the ribbon marks the open view.
- Windows contrast themes: text and icons inside selected and current items (selected pages, the chosen option, the current tab or view) use the highlight text color.
- Settings → Sicherheit → „Schlüssel wechseln“ re-encrypts the database with a new key without decrypting it: the new recovery key is shown to print or save first, after the restart only it opens the database, and backups from then on use it. A crash during the change leaves the previous or the new state, never half of it; a password-protected key keeps its password.
- A large vault import (thousands of notes) is written in batches: the app stays usable meanwhile, the progress shows „1200 von 20000 Seiten angelegt“, and cancelling (or a crash) removes the pages written so far instead of leaving half a vault.
- Error messages no longer end in SQLite's or the system's English text („Error code 13: …“); it is behind „Details“ in the message.

## Fixed

- Edits whose save failed were lost when the note was closed or another page opened in its tab: they are now kept, saved again every few seconds, shown when the page is opened again, and „Beenden“ asks before quitting while they are not saved. The Markdown source view retries failed saves as well (it showed the error and then stopped).
- Restoring a backup from before the encryption into an encrypted workspace left the database unencrypted; it is now encrypted when it is put in place.
- A backup cut off while it was written (the app killed, a full disk) left a truncated file under a backup's name, which counted as the newest backup and pushed a good one out of the rotation. Backups are now written to a temporary file and renamed when complete.
- The Git sync no longer stops at „Zur Sicherheit angehalten“ when „Aufräumen“ moved many notes into folders and git's rename detection is switched off in the user's git configuration.
- Cancelling a vault import says „Import cancelled“ in the English interface.

- Notes keep the Markdown other tools wrote when you edit them: same-page links `[[#Abschnitt]]` were turned into text, link targets in angle brackets (`[Plan](<Ordner/Mein Plan.md>)`) lost them and broke on the next save, `&nbsp;` became `&amp;nbsp;`, a `|` in inline code in a table split the cell, inline code containing backticks was cut, and the blank line under the frontmatter was removed on every save.
- A task list directly under a bullet list is no longer saved with a blank line between them, and table columns with links, inline code or alignment are padded to their real width.
- The timesheet's week overview no longer marks public holidays, vacation or sick days as below target, counts half days by half and uses the target per weekday („Saldo und Urlaub“, e.g. Friday 5 h); the week's target („Soll“) does the same. The day review, the week proposal, the start page and the reminders use the target per weekday as well (they used the daily target).
- The end-of-day reminder („Heute 0 von 8 h gebucht“) no longer comes on public holidays and absence days, and reminds of half the target on half days.
- Kalender: on the days the clocks change (25 October 2026, 28 March 2027) appointments, focus blocks and bookings after 02:00 were drawn an hour off. Moving a focus block to another day across a clock change keeps its time of day.
- „In CATS kopieren“ rounds so that every day adds up (three times 20 minutes are 0,33 + 0,34 + 0,33 h, not 0,99 h), like the CATS file export.
- Quick booking in the timesheet books once when Enter is pressed twice.
- A booking in the Kalender's time lane opens the timesheet on its week (it opened the current week).
- 31 October 2017 (500 years of the Reformation) counts as a public holiday in every state.
- Stop in the assistant, the inline AI bar and the meeting summary now ends a request at once also while Arcalo is still asking the AI server for its models or searching the notes; before, the request kept running (and was billed) until the server answered.
- „Empty answer from the AI server“ is shown in English in the English UI.
- Jira errors no longer read „KI-Server meldet Fehler 401: …“: the Jira message stands alone, in Settings, the connection test, the Issues page and notifications.
- Calendar files from older Outlook or Exchange exports in Windows-1252 keep their umlauts, € and quotes; calendar files saved as UTF-16 („Unicode“) are read.
- Dragging a page onto one of its own subpages no longer shows a drop marker and then fails with „Verschieben fehlgeschlagen“.
- Tab from the command palette no longer moves the focus into the app behind it; Tab in an open menu closes it.
- The sidebar search showed „0 Seiten“ without „Keine Treffer“ when only time entries matched while time tracking is off.
- Saving the app lock PIN when the credential store refuses it no longer reports „App-Sperre eingerichtet“ and closes the dialog; the error shows and the dialog stays open.
- Ctrl+F in the settings goes to the search field in narrow panes too (with the right panel open it did nothing).
- Settings → Notizen shows the daily note template's full name instead of cutting it off.
- The password dialog for a portable database copy saves with Enter; a Windows Hello or Touch ID prompt that cannot start shows a note on the lock screen.
- Text selected right after clicking into a note (while the note still loads) no longer collapses to the cursor a moment later, so Ctrl+J opens the inline AI bar for it instead of the assistant.
- After restoring an older backup, the Git sync no longer pushes the restored state over newer notes on the server as if it were new work: it compares first and, when they differ, asks under Settings → Sicherung whether to get the newer state from the server (the restored text stays in the page versions; notes changed only here become conflicts to merge) or to upload the restored state (the newer one stays in the server's history).
- Files that only older versions of a page or a stored e-mail use are no longer listed as unused and offered by „Unbenutzte aufräumen“; they are marked „Nur in alten Versionen“ or „Gespeicherte E-Mail“. Restoring a version brings files it needs back from the file trash.
- Linux desktops whose desktop portal does not answer: Arcalo no longer freezes for several seconds right after the start while it prepares the quick-capture window; it is prepared once you are idle, or on first use.

## Checklist for Windows (manual)

- Copy Markdown from Notepad and from VS Code and paste it into a note: it appears formatted; „Als Text einfügen“ gives the plain text back. Text copied from Word or a web page keeps its own formatting.
- Alt+Enter on a `[[link]]` and on a web link in a note opens it (WebView2 must not show its own menu for Alt).
- Kalender on 25 October 2026 with Windows in the German time zone: an Outlook appointment at 10:00 is drawn at 10:00.
- Timesheet with a vacation day entered in the Kalender: no „Unter Soll“ chip for it; „In CATS kopieren“ pasted into SAP CATS gives day totals that match the week overview.
- Settings → KI & Modelle with the company AI server: in the assistant, ask a question and press Stop at once: the answer stops within a second and the server log shows no chat request.
- Settings → Jira: connect a company Jira Server whose certificate comes from the company CA without adding the CA: the test names the certificate and Settings → Netzwerk; add the CA there and test again.
- Settings → Kalender: subscribe to an Outlook-on-the-web „HTML“ link instead of the ICS link: the error says to copy the ICS link; with the ICS link the calendar syncs.
- Data safety: fill the drive that holds the data folder (or make `workspace.db` read-only in its properties), type in a note: „Nicht gespeichert – Arcalo versucht es weiter“ stays at the top; open another page, free the space, open the note again: the text is there and saved. Tray → „Beenden“ while it is not saved asks first.
- Encrypt the database (Settings → Sicherheit), then restore a backup from before the encryption: after the restart Settings → Sicherheit shows the database as encrypted and the notice says the backup was encrypted.
- Contrast theme (Windows Settings → Accessibility → Contrast themes, e.g. Desert or Night sky): select three pages in the tree with Shift+click and open a context menu with the keyboard (Shift+F10): selected rows, the highlighted menu item and the current tab show their text in the highlight text color, nothing faint on the highlight.
- Narrator: Ctrl+K, type „ubersicht“, arrow through the results: each result is read; Shift+F10 on a page in the tree reads the first menu item, Escape returns to the page.
- Change the database key (Settings → Sicherheit → „Schlüssel wechseln“) on an encrypted workspace with a password set: print the new recovery key, restart; the workspace opens, „Wiederherstellungsschlüssel anzeigen“ shows the new key; the portable copy on a second computer opens with the same password; the old recovery key is refused on the recovery screen.
- Git sync with a company Git server: restore yesterday's backup (Settings → Sicherung), restart, sync: the toast asks to decide; „Neueren Stand vom Server holen“ brings today's notes back and the server's history shows no new commit.
