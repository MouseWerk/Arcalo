Arcalo 1.12.0

## Improved

- Microsoft Store build: Arcalo can be installed from the Microsoft Store as a package Microsoft signs, so Windows no longer warns about an unknown publisher. The Store version updates through the Store (Settings → Über → Updates says so and opens the Store); it has no own update check, rollback or portable mode, starts with Windows through its startup task (Windows Settings → Apps → Autostart) and keeps its data in the same folder as the installer version (docs/release/microsoft-store.md).
