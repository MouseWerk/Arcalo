Arcalo 1.12.0

## Improved

- Microsoft Store build: Arcalo can be installed from the Microsoft Store as a package Microsoft signs, so Windows no longer warns about an unknown publisher. The Store version updates through the Store (Settings → Über → Updates says so and opens the Store); it has no own update check, rollback or portable mode, starts with Windows through its startup task (Windows Settings → Apps → Autostart) and keeps its data in the same folder as the installer version (docs/release/microsoft-store.md).
- Pasting Markdown copied as plain text (from a `.md` file, a code editor or an AI chat) now shows it formatted: headings, lists, tasks, tables, bold and links instead of literal `#`, `-` and `**`. „Als Text einfügen“ turns it back into the plain text.
- Links to a section now go there: `[[Seite#Abschnitt]]` and `[[Seite#^id]]` open the page scrolled to that heading or block (briefly highlighted), and same-page links `[[#Abschnitt]]` work as in Obsidian.
- Alt+Enter follows the link at the caret (Ctrl+Alt+Enter in a new tab), so links can be opened without the mouse.
- Find in page brings the first match into view while you type.
- The paragraph style in the editor toolbar shows its full name („Überschrift 1“ instead of „Übersch…“) in narrow panes.
- `/zeit` understands time spans: `/zeit NP-8801/1020 9:00-10:30 Abstimmung` books 1,5 h from 9:00 (also `9.00–10.30` and over midnight, `22:00-01:00`). On a page linked to a Vorgang the span can come first, like a duration.
- `/zeit` lines starting with any duration the booking understands (`1h30m`, `90mins`, `2std.`) are recognized as such in the editor, and without a reference the error now says the Netzplan is missing instead of „Ungültige Dauer“.
- A `/zeit` booking for an earlier day without start time now begins after that day's last booking instead of all at 08:00, so the Kalender shows them one after another.
- New time entries and the timer start with the Netzplan's default Leistungsart from Settings → Zeiterfassung (it was always DEV).
- The duration field of a time entry accepts `1h 30m`, `90 min` and `1,5 Std.` as well.
- In a narrow pane the timesheet's week navigation gets its own row, so the actions stay together.
- Without a connected AI, the inline AI bar (Ctrl+J), „Besprechung zusammenfassen“ and the assistant show „Keine KI verbunden“ with a „KI einrichten“ button that opens Settings → KI & Modelle, instead of actions that fail; „Tags mit KI vorschlagen“ only appears once a provider can be asked.
- Failed requests in the inline AI bar, the meeting summary and the day review summary now say what went wrong and how to fix it (as the assistant does), with the server's message under „Details“ and „Verbindung prüfen“; that button always opens the AI section of the settings.
- A provider whose key the server rejects shows „Zugang abgelehnt – Schlüssel prüfen“ in Settings → KI & Modelle instead of „Keine Verbindung“.
- Settings → Sprachnotizen has a title and a short introduction like the other sections.
- Jira errors say what happened and how to fix it: a certificate the computer does not trust (a company certificate authority) points to Settings → Netzwerk (add the root certificate or trust the server), an unknown server name to a typo or the VPN, a refusing proxy to the proxy profile, a proxy asking for a login (407) to its user and password, a gateway or server error (5xx) to trying again in a few minutes; a refused login names the token of the site's kind (API token or personal access token) and where to create a new one.
- A saved JQL search that Jira rejects (a typo, a field that does not exist) shows its error under the search in Settings → Jira until a sync runs it again, instead of failing silently.
- Settings → Jira takes intranet addresses without a dot (`https://jira`, `http://jira:8080`), and an address copied from the browser (`…/browse/PROJ-123`, a board link) keeps only the site's base.
- A calendar subscription that returns a web page (a login or sharing page instead of the calendar) says to copy the calendar's ICS link; 401, 403, 404 and server errors of a subscription say how to fix them.
- The Issues page's warning for a failing Jira site dates the shown issues by that site's last good sync and opens Settings → Jira.
- Settings → Jira: JQL and site addresses show `!=` and `://` as typed (no font ligatures), the saved searches block has room below its add row, the sync row says „Alle Jira-Sites jetzt abgleichen“; dialogs leave room between a field's hint and the next field.

## Fixed

- Notes keep the Markdown other tools wrote when you edit them: same-page links `[[#Abschnitt]]` were turned into text, link targets in angle brackets (`[Plan](<Ordner/Mein Plan.md>)`) lost them and broke on the next save, `&nbsp;` became `&amp;nbsp;`, a `|` in inline code in a table split the cell, inline code containing backticks was cut, and the blank line under the frontmatter was removed on every save.
- A task list directly under a bullet list is no longer saved with a blank line between them, and table columns with links, inline code or alignment are padded to their real width.
- The timesheet's week overview no longer marks public holidays, vacation or sick days as below target, counts half days by half and uses the target per weekday („Saldo und Urlaub“, e.g. Friday 5 h); the week's target („Soll“) does the same. The day review, the week proposal, the start page and the reminders use the target per weekday as well (they used the daily target).
- The end-of-day reminder („Heute 0 von 8 h gebucht“) no longer comes on public holidays and absence days, and reminds of half the target on half days.
- Kalender: on the days the clocks change (25 October 2026, 28 March 2027) appointments, focus blocks and bookings after 02:00 were drawn an hour off. Moving a focus block to another day across a clock change keeps its time of day.
- „In CATS kopieren“ rounds so that every day adds up (three times 20 minutes are 0,33 + 0,34 + 0,33 h, not 0,99 h), like the CATS file export.
- Quick booking in the timesheet books once when Enter is pressed twice.
- A booking in the Kalender's time lane opens the timesheet on its week (it opened the current week).
- 31 October 2017 (500 years of the Reformation) counts as a public holiday in every state.
- Stop in the assistant, the inline AI bar and the meeting summary now ends a request at once also while Arcalo is still asking the AI server for its models or searching the notes; before, the request kept running (and was billed) until the server answered.
- „Empty answer from the AI server“ is shown in English in the English UI.
- Jira errors no longer read „KI-Server meldet Fehler 401: …“: the Jira message stands alone, in Settings, the connection test, the Issues page and notifications.
- Calendar files from older Outlook or Exchange exports in Windows-1252 keep their umlauts, € and quotes; calendar files saved as UTF-16 („Unicode“) are read.

## Checklist for Windows (manual)

- Copy Markdown from Notepad and from VS Code and paste it into a note: it appears formatted; „Als Text einfügen“ gives the plain text back. Text copied from Word or a web page keeps its own formatting.
- Alt+Enter on a `[[link]]` and on a web link in a note opens it (WebView2 must not show its own menu for Alt).
- Kalender on 25 October 2026 with Windows in the German time zone: an Outlook appointment at 10:00 is drawn at 10:00.
- Timesheet with a vacation day entered in the Kalender: no „Unter Soll“ chip for it; „In CATS kopieren“ pasted into SAP CATS gives day totals that match the week overview.
- Settings → KI & Modelle with the company AI server: in the assistant, ask a question and press Stop at once: the answer stops within a second and the server log shows no chat request.
- Settings → Jira: connect a company Jira Server whose certificate comes from the company CA without adding the CA: the test names the certificate and Settings → Netzwerk; add the CA there and test again.
- Settings → Kalender: subscribe to an Outlook-on-the-web „HTML“ link instead of the ICS link: the error says to copy the ICS link; with the ICS link the calendar syncs.
