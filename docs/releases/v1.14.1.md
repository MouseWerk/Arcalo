Arcalo 1.14.1

## Improved

## Fixed

- Windows: backups failed since 1.12 with „Keine Berechtigung“ (access denied) when the finished file was flushed to disk, so no new backup was written, also not the one before an update. Backups are written again; the Windows build now runs the backup tests on Windows.
- Installing an update from inside the app failed since 1.12 with „Installation fehlgeschlagen: The configured updater endpoint must use a secure protocol like `https`“. It works again: the downloaded and verified update is installed directly.
- Because the failing code is part of the installed version, copies running 1.12 to 1.14.0 cannot update themselves to 1.14.1: install 1.14.1 once by hand from the release page (Windows: run the setup over the installed version; macOS: replace Arcalo in Programme; Linux: replace the AppImage). Notes and settings stay. Later updates install from inside the app again.

- Kalender: a focus block you pick after its time is over now shows as picked (stronger fill, bold title) like one still to come.

## Checklist for Windows (manual)

- Settings → Sicherung → „Jetzt sichern“: a new file `arcalo-….db` appears in the backup folder and the developer log shows no „Keine Berechtigung“.
- Manual update from 1.14.0: with 1.14.0 installed and some notes and changed settings, run `Arcalo_1.14.1_x64-setup.exe` from the release page over it. Arcalo starts as 1.14.1, Settings → Über shows 1.14.1, notes, settings, the tray icon and the start menu entry are unchanged, and „Apps & Features“ lists Arcalo once.
- In-app update from 1.14.1: with 1.14.1 installed (release build) and the next version published, Settings → Über → „Jetzt nach Updates suchen“ → „Installieren und neu starten“. The window and the tray icon go, the installer runs with its progress window only, and Arcalo starts again as the new version with the „aktualisiert“ toast; no „secure protocol like `https`“ error, and the log shows „starting …-installer.exe /P /UPDATE /R /ARGS“. Same with the mode „Automatisch“ via „Beenden“ (installs on quit, without the relaunch). Further cases: `docs/testing/auto-update-windows.md`.
