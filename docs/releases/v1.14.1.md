## Fixed

- Windows: backups failed since 1.12 with „Keine Berechtigung“ (access denied) when the finished file was flushed to disk, so no new backup was written, also not the one before an update. Backups are written again; the Windows build now runs the backup tests on Windows.

## Checklist for Windows (manual)

- Settings → Sicherung → „Jetzt sichern“: a new file `arcalo-….db` appears in the backup folder and the developer log shows no „Keine Berechtigung“.
