Arcalo 1.10.0

## New

- **Linux keyring**: API keys, the Git token, the proxy password, calendar addresses and Jira tokens go into the Secret Service (GNOME Keyring, KWallet, KeePassXC) under the same service name „Annalo“ as on Windows and macOS. Only when no Secret Service answers (a headless machine, a desktop without a keyring) they stay in `secrets.json` in the data folder (readable by the user only); `ANNALO_SECRET_STORE=file` keeps the file on purpose. Settings → Datenschutz → „Zugangsdaten“ shows which store is used and, for the file, why.
- **Moving the old file over**: on the first start with a Secret Service, every entry of `secrets.json` is written to the keyring, read back and compared, and only then removed; the file is deleted once empty. An entry that cannot be moved stays in the file and is still read. Portable copies keep their own entries (`<name>@<folder id>`) in the keyring of the computer, as on Windows and macOS: on another computer the credentials are entered once more.
- **Structured developer log**: Settings → Protokoll → „Protokollstufe“ (Nur Fehler, Warnungen, Info, Debug, Trace; „Ausführliches Protokoll“ of earlier versions becomes Debug), or `ANNALO_LOG` (`debug`, or directives such as `annalo=trace,zbus=debug`), which wins over the setting. Git sync, AI requests, calendar and Jira syncs, backups, database migrations, update checks, downloads and installs write their duration (`… done elapsed_ms=…`) with their details. „Zusätzlich als JSON-Zeilen“ writes the same entries to `logs/annalo.jsonl`. Both files rotate at 1 MB and keep three old ones. Every message and every field is redacted before it is written (tokens, passwords, keys, credentials in URLs, stored secrets); fields named like a secret are never written.
- **„Diagnosepaket erstellen“** (Settings → Protokoll): a zip for bug reports with version and system (`info.json`: OS and version, architecture, portable mode, credential store, log level, database schema version), the effective settings without secrets (`settings.json`) and the latest log files, saved where you choose.
- **Notifications with buttons**: tasks due today (from 09:00, Settings → Benachrichtigungen „Fällige Aufgaben“) with „Erledigt“, „Schlummern“ (10 Min, 1 Std, morgen 09:00) and „Öffnen“; the morning briefing with „Öffnen“; the end of a focus session with „+5 Min“, „Pause“ and „Öffnen“; a downloaded update with „Jetzt neu starten“ and „Später“. Clicking the notification opens the note, the briefing or the window. A snoozed reminder is stored in the workspace and comes back after a restart. Windows: toasts whose buttons start Arcalo through the `arcalo-notify:` address (registered for the user, removed by the uninstaller) and reach the running app, also from the Action Center; Linux: notification actions of the desktop; macOS: the notification without buttons, a click brings Arcalo to the front.
- **Settings apply at once**: every change in the settings is stored immediately, with „Rückgängig“ in a toast for each change (typing counts as one change and is stored once it pauses). Addresses, times and numbers apply when the field is left or on Enter and show what is wrong right below the field. Switching off something that takes effect broadly (time tracking, the Git sync, a removed AI provider or backup target) still applies at once and keeps its undo longer. The save bar („Speichern“ / „Verwerfen“) is gone.
- **„Abschnitt zurücksetzen“** at the top of every section with defaults (Darstellung, Editor, Notizen, Zeiterfassung, KI, Jira, Ordner & Ablage, Sprachnotizen, …), with undo.
- **For all workspaces or only this one**: Darstellung, KI (providers and models), Ordner & Ablage, Jira and the start page widgets can be shared by every data folder on the computer („Für alle Arbeitsbereiche“, kept in `shared-settings.json` in the app's config folder; portable copies next to `data`) or kept for one („Nur dieser Arbeitsbereich“). A workspace that already had its own values keeps them on the update; a new data folder starts with the shared ones. Start page and filing stay per workspace unless shared on purpose.
- **Settings sync across computers** (opt-in, Einstellungen → Sicherung → Git-Synchronisierung → „Einstellungen synchronisieren“): the settings are written as `settings.json` into the synced repository and merged per setting, the later change wins. Never in the file: credentials (any key named like a token, password, key, secret or credential, and URLs with a password), folders and paths, window and backdrop, devices, proxy and network, update policies, AI connections, Jira sites, calendars, the start page and the log settings. What a sync took over is logged, announced with „Rückgängig“ and shown under „Letzter Abgleich der Einstellungen“ with „Abgleich rückgängig machen“.
- **Grouped settings menu**: Allgemein, Arbeiten, KI & Sprache, Daten & Sicherheit, System, each collapsible (remembered); the group of the open section always shows, the search still finds every section, and the menu scrolls below the search at any window height.
- **Settings version and migrations**: the stored settings carry a `version`; older settings run through an ordered chain of steps once at start (logged under „settings“): start preferences, AI providers, window backdrop, calendar list, start page clean-up, and the 1.10 log level („Ausführliches Protokoll“ becomes Debug) and „Fällige Aufgaben“. Keys a newer version wrote are kept when this version saves, at any depth. The settings' JSON Schema is in `docs/settings.schema.json`.

- **Proxy profiles** (Settings → Netzwerk): named ways out such as „Firma“, „VPN“ or „Direkt“, each with its mode (direct, system incl. WinINet and AutoConfigURL, manual HTTP(S)/SOCKS5 with user and a password in the credential store, PAC URL or file), exceptions, extra root CAs and connect/read timeouts. Add, edit, duplicate and delete; the existing setting becomes the profile „Standard“ with exactly the same behavior.
- **A profile per service**: updates (feed and download), release notes, each AI provider, each Jira site, the Git sync, each ICS subscription, Whisper model downloads, link titles and the assistant's HTTP requests choose „Standard-Profil verwenden“ or a profile. The table shows the effective route („über Proxy firma:8080“, „direkt“, „PAC → DIRECT“) and „Testen“ sends a real request to the service's target (feed, model list, Jira site, `git ls-remote`, model source, calendar). Every client is built in one place (`network::client_for`), the Git environment by `network::git_env_for`; requests log service and route at debug level (host only, no credentials).
- **„Diesem Server vertrauen“**: instead of the global „Ungültige Zertifikate akzeptieren“, single servers are trusted by the SHA-256 of their certificate (any other certificate of that host is rejected). A test that fails on the certificate offers „Zertifikat anzeigen und vertrauen“. Git pins the server's public key (`http.pinnedPubkey`). Profiles that had the old switch on keep it, marked „unsicher“, until „In vertraute Server umwandeln“.
- **Network policies** (docs/admin/network.md): `NetworkRoute.<service>` sets and locks a service's profile (`NetworkRoute.ai` for all AI providers), `LockNetworkProfiles` locks the profiles; registry, plist and `policy.json` as for the update policies. Proxy profiles stay on the computer (not in the settings sync).

- **„Datenbank verschlüsseln“** (Settings → Daten & Sicherheit → Sicherheit, and the optional setup step „Sicherheit“; off by default): SQLCipher with a random 256-bit key in the credential store. Arcalo restarts once, exports, checks (integrity, row count per table, schema version) and swaps atomically; a crash at any step is rolled back or finished at the next start. The previous file is overwritten and deleted at the next start (best effort on SSDs). „Entschlüsseln“ works the same way back.
- **Recovery key** (56 characters in groups of four, with a checksum): shown when encrypting, with „Ausdrucken“, „Speichern als Datei“ and a confirmation. A missing or wrong key at the start opens a recovery screen („Mit Wiederherstellungsschlüssel öffnen“, „Letzte Sicherung wiederherstellen“) instead of the app. Portable copies can also protect the key with a password (Argon2id, AES-256-GCM) to open on other computers.
- **Encrypted backups**: backups of an encrypted database are encrypted with the same key and restore with the recovery key alone; checksums and destination copies are unchanged. The Markdown mirror, the Git sync and attachments stay plaintext (said next to the switch). Details and limits: `docs/security/encryption.md`.
- **App-Sperre**: a PIN (Argon2id hash in the credential store) at the start, after N minutes without input and after sleep; Windows Hello and Touch ID optional. While locked the app is not loaded and its commands are refused, quick capture and search show the lock screen, the tray offers only „Entsperren“ and „Beenden“, notifications carry no content. Growing waits after wrong PINs; a forgotten PIN is reset only with the system sign-in or the recovery key.
- Build: rusqlite `bundled-sqlcipher` – CommonCrypto on macOS, a vendored static OpenSSL on Windows and Linux (the Windows jobs use the runner's Strawberry Perl).

## Fixed

- A restart (update, „Jetzt neu starten“) no longer repeats a notification click Arcalo was started with.
- „Neu in Arcalo“ for 1.9 showed German pictures in English, and one of them pages of the automated tests: every picture now exists per language, made from the sample data (`en.image` / `de.image` in the highlights files).


## Checklist for Windows (manual)

- [ ] Task due today: the toast shows „Erledigt“, „10 Min“, „1 Std“, „Morgen“, „Öffnen“; „Erledigt“ ticks the task in the note (open editor updates).
- [ ] „10 Min“: the toast comes back after ten minutes; „Morgen“ after quitting and starting Arcalo again: the snooze survives the restart and the toast comes back at 09:00.
- [ ] Clicking the toast body opens the note in Arcalo, also when Arcalo was minimized to the tray, and also from the Action Center after the toast left the screen.
- [ ] A button clicked in the Action Center while Arcalo is not running starts Arcalo and runs the action (the note opens after the start).
- [ ] Focus end: „+5 Min“ starts a 5-minute session, „Pause“ shows the break, „Öffnen“ brings the window to the front.
- [ ] Update downloaded: „Jetzt neu starten“ installs and restarts; „Später“ leaves it for the quit.
- [ ] `HKCU\Software\Classes\arcalo-notify` points at the installed `arcalo.exe`; it is gone after uninstalling (not after an update). A portable copy registers nothing and shows toasts without buttons.
- [ ] Credentials still found after the update (Credential Manager, service „Annalo“); Settings → Datenschutz shows „Windows-Anmeldeinformationsverwaltung“.
- [ ] Settings → Protokoll: level change takes effect without a restart; „Diagnosepaket erstellen“ saves a zip that opens in Explorer and shows the Windows version in `info.json`.
- [ ] Settings: a change applies without a save button, the toast's „Rückgängig“ restores it; „Abschnitt zurücksetzen“ and its undo.
- [ ] Two data folders (Einstellungen → Sicherung → Datenordner): the theme set „Für alle Arbeitsbereiche“ appears in the other folder after the restart; `%APPDATA%\app.annalo.desktop\shared-settings.json` holds it. A portable copy keeps the file next to `data`.
- [ ] Two computers with the same Git remote and „Einstellungen synchronisieren“: a changed setting arrives after the next sync with a toast; `settings.json` in the repository has no token, password or folder path.
- [ ] Settings menu at 125 % display scaling and a window of 760 px height: no item under the search, the menu scrolls.
- [ ] Corporate proxy with PAC (profile „Standard“ in mode PAC from the company's `wpad.dat`) and a profile „VPN“ in mode „Direkt“ for one Jira site reached through the VPN: Settings → Netzwerk shows „PAC → PROXY …“ for updates and AI and „direkt“ for that site; „Testen“ succeeds on each row; an update check and a Jira search work; with the developer log at Debug, `net` lines show each service with its route and no password.
- [ ] Upgrade from 1.9 with „Ungültige Zertifikate akzeptieren“ on: the profile shows „unsicher“; „In vertraute Server umwandeln“ lists the servers with an own certificate and clears the badge.

## Checklist for encryption and app lock (Windows, macOS; manual)

- [ ] Windows: encrypt a workspace; Credential Manager shows `Annalo` / `db-key`; after the restart the notes are there and `workspace.db` holds no readable text.
- [ ] Windows: delete the `db-key` credential; the start shows the recovery screen; the printed recovery key opens it and stores the key again.
- [ ] Windows: App-Sperre with „Mit Windows Hello entsperren“: the prompt comes up in front of the main window; cancelling leaves it locked; the PIN still works. „PIN vergessen?“ → „Mit Windows Hello zurücksetzen“ switches the lock off.
- [ ] Windows: while locked, the capture shortcut and the jump list only show the lock screen; the tray menu has only „Entsperren“ and „Beenden“; a due-task toast says nothing about the task and has no buttons.
- [ ] Windows: with „Nach dem Ruhezustand sperren“, Arcalo is locked after the laptop wakes up.
- [ ] macOS (Apple silicon and Intel builds): encrypt; the keychain item `Annalo` / `db-key` exists; the restart opens the workspace.
- [ ] macOS: „Mit Touch ID“ on the lock screen; on a Mac without Touch ID the option is not offered; „PIN vergessen?“ with Touch ID or the account password resets the lock.
- [ ] Portable stick with a password-protected key on a second computer: the recovery screen asks for the password; with „Auf diesem Rechner merken“ off no credential is left behind.
