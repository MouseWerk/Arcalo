Annalo 1.3.0

## New

- **Windows installer in Annalo's design**: the welcome and finish pages show the Annalo logo on the dark brand background, every page header shows the app icon, and the installer and uninstaller use the Annalo icon. German and English.
- **AI providers**: next to LiteLLM, any OpenAI-compatible endpoint (OpenAI, Azure OpenAI, Mistral, Groq, OpenRouter, LM Studio, vLLM) and Ollama.
  - Ollama on this computer is found automatically; its models are listed and missing ones can be downloaded.
  - Each tier (Lokal, Standard, Reasoning) and the embedding model use their own provider and model.
  - `#privat` and "nur lokal" content only goes to providers marked local, also when a provider fails and another takes over.
  - "Verbindung testen" checks each provider step by step: reachable, key, chat, tools, embeddings.
  - Costs come from an editable price table when the provider does not report them; local providers are free.
  - Existing LiteLLM setups keep working without changes.
