Annalo 1.3.0

## New

- **Windows installer in Annalo's design**: the welcome and finish pages show the Annalo logo on the dark brand background, every page header shows the app icon, and the installer and uninstaller use the Annalo icon. German and English.
- **AI providers**: next to LiteLLM, any OpenAI-compatible endpoint (OpenAI, Azure OpenAI, Mistral, Groq, OpenRouter, LM Studio, vLLM) and Ollama.
  - Ollama on this computer is found automatically; its models are listed and missing ones can be downloaded.
  - Each tier (Lokal, Standard, Reasoning) and the embedding model use their own provider and model.
  - `#privat` and "nur lokal" content only goes to providers marked local, also when a provider fails and another takes over.
  - "Verbindung testen" checks each provider step by step: reachable, key, chat, tools, embeddings.
  - Costs come from an editable price table when the provider does not report them; local providers are free.
  - Existing LiteLLM setups keep working without changes.
- **Property types**: text, selection (with colors), multiple selection, number, date, person, checkbox and link, set once for all subpages of a page (`eigenschaften:`). Typed controls instead of free text; invalid values are marked, never changed.
- **Table and board views**: a page's subpages as a table (sort, filter, resize and reorder columns, edit every cell, keyboard navigation, fast with hundreds of pages) or as a Kanban board (drag cards between columns to change their status, reorder, collapse columns). Chosen in the page's "…" menu and saved with the page.
- **Settings redesigned**: a menu with groups and icons, search across every section (also theme names), rows whose controls move below the text when space is short, long paths shortened in the middle with a copy button. In narrow windows the menu becomes a section picker. The update row in "Über" no longer cuts off buttons.
- **20 themes**: Annalo, Catppuccin, Nord, Dracula, Solarized, Gruvbox, Tokyo Night, GitHub, One Dark, Rosé Pine, Everforest and high contrast, in light and dark. A picker with previews; with "System" Annalo switches between your light and dark theme. Your own themes with a color editor and live preview, exported and imported as a file.
- **New dropdowns** everywhere, in Annalo's design instead of the plain Windows list, with full keyboard support and type-ahead.
- **Attachment manager** ("Anhänge", Ctrl+K or Settings → Verwaltung): every image, drawing, PDF and file with preview, type, size, date and the pages that use it. Filter by type, unused or large files, search by name or page, sort. Rename safely (every embed in every page is rewritten, the old text stays a version), delete into the trash with a warning when the file is still used, and "Unbenutzte aufräumen" with the space it frees. Deleted files can be restored from the trash.
- **Git sync with several computers**: notes another computer changed are taken over. A note changed here and there becomes a conflict instead of a failed sync: both versions are kept, the page is marked "Konflikt", and the merge view shows both versions side by side by paragraph, heading and list item. Changes on one side merge by themselves; per conflict you pick "Meine", "Andere", "Beide" or write your own text. "Übernehmen" saves and syncs.
- **Portable version for Windows**: a ZIP next to the installer. Unpacked on a USB stick, Annalo keeps all data in `data` beside `Annalo.exe` and writes nothing to the computer's user profile (no autostart, no jump list; updates are downloaded from the release page). API keys and tokens stay in the credential store of each computer.
- **PDFs**: large PDFs no longer freeze the window (pdf.js parses in a background worker), pages render as they come into view and far pages free their memory. Text can be selected and copied, search highlights every hit with next/previous, Chinese, Japanese and Korean text renders. A PDF dropped on the tab bar opens in its own tab.

## Fixed

- **A note with an image on a line of its own** (`![Bild](attachments/bild.png)`) could make the window go blank on the first edit.
- **Grey, washed-out sidebar on Windows 11**: the see-through effect (Mica) is now off by default; when switched on, the sidebar uses the theme's color and stays readable.
