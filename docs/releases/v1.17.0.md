Arcalo 1.17.0

## Improved

- The data that Arcalo kept twice since the move to the new folders in 1.15 is deleted: the folders of version 1.14 and earlier (data, settings, the window's storage) and their old entries in the credential manager, once Arcalo has started on the copies. It happens in the background after the start and is shown once with the space freed. Folders that something still uses (a chosen data folder, the backup folder, the Markdown copy, a backup destination, a return to 1.14) are kept, and a portable copy leaves the computer's folders alone.
- Switching tabs is steadier: the tabs a pane keeps open in the background stay exactly where they are, so switching back and forth many times never reloads a note or view; scroll position, cursor and undo history stay as you left them.
- English wording: the week proposal offers “Apply all” and “Apply {n}”, the ribbon groups “Add from the ribbon…”, the theme editor “Copy colors from”, and a conflict “Use theirs”, instead of literal “take over” phrases.
- Narrow panes: the note's toolbar fades out at the edge where buttons are hidden instead of showing one cut in half; the start page shows “von 40,00 h” on one line; the „Wochenrückblick“ button next to the calendar title is easier to hit.
- Long notes open faster and switch to the Markdown source view almost at once: the note is drawn once instead of twice, and leaving the visual editor (for the source view or by closing the tab) no longer draws it again.
- Typing in long notes with code, diagrams, tables, chat logs and time chips stays fast: per key only the edited part is looked at again, not the whole note. In a note of 1 MB a key takes about a third less time than before.
- Time tracking, Projekte, the calendar, the start page and the property pickers share one copy of the projects and Leistungsarten: opening them in new tabs reads nothing again until something changes.
- Large workspaces: the page tree and the graph load half the data or less, the Jira issue list 40 % less; tag suggestions, duplicate hints and unlinked mentions of the opened page no longer hold up the next page switch.

## Fixed

- Git sync: two computers that attach a different file with the same name (for example „Bericht.pdf“) keep both files. The file on the server keeps its name, the other one gets its name with a short code added („Bericht-1a2b3c4d.pdf“), and each note shows the file it was written with on both computers. This holds for the first sync of a new computer as well. Before, the two files replaced each other in the repository with every sync, and a new computer's first sync replaced the file on the server.
- With the window split, a command from the command palette that shows a tab of the other pane no longer jumps back to the pane you came from.
- Kalender: on a Saturday (or with six workdays) today's head in the work week keeps the daily note, the booked hours and the review on one row.
- A dropdown opened with the keyboard starts on the chosen value, also when the mouse pointer rests where the list opens (Enter picked the option under the pointer).
- Projekte in a narrow pane: „Netzplan“ and the project menu stay inside the project's card; the booked hours under a Vorgang no longer run into the next column.

## Checklist for Windows (manual)

- Install 1.14, add a page, a picture and an API key, update to 1.16, start once, then update to 1.17: 10 seconds after the start the message „Alte Daten aufgeräumt“ names the freed space; `%APPDATA%\app.annalo.desktop` and `%LOCALAPPDATA%\app.annalo.desktop` are gone, the page, the picture and the API key are still there, and the Windows Credential Manager („Anmeldeinformationsverwaltung“ → Windows-Anmeldeinformationen) lists no entries named „Annalo“ any more, only „Arcalo“. A second start shows no message.
- Same as above, but with Settings → Sicherung → „Eigener Ordner“ for the backups set to a folder inside `%APPDATA%\app.annalo.desktop` before the update to 1.17: that folder is not deleted, no message names it, and Settings → Protokoll shows why it was kept.
- Two computers with Git sync: on A attach a file „Bericht.pdf“ to a note and sync; on B attach a different file also named „Bericht.pdf“ to another note and sync, then sync A: both computers show both files (one as „Bericht-…pdf“), each note opens its own file, and syncing both again changes nothing. Then set up a third computer with its own „Bericht.pdf“ and connect it to the same repository: after its first sync A's file is unchanged on A and B, and the third computer's note opens its own file.
- English UI: Time tracking → “Plan the week's bookings”: the buttons read “Apply all” and “Apply 3” (with three lines ticked).
- Open five long notes in five tabs, scroll each to a different place and type a word in each; switch between the tabs with Ctrl+Tab and clicks for a minute: no flicker, every note keeps its scroll position and cursor, and Ctrl+Z takes back the word in each.
- Split the window (Rechts teilen), open Kalender on the right, click into the note on the left, then choose „Kalender“ in the command palette: the right pane is active and stays so.
- Window at 1280 px with the side panel open and the window split: the note's toolbar on the left fades out at its right edge; Projekte on the right shows the project menu „…“ inside the card.
- Settings → Darstellung: rest the mouse pointer just below „Skalierung“, move to the dropdown with Tab and press ↓: „100 %“ is highlighted, not the option under the pointer.
- On a Saturday, Kalender → „Arbeitswoche“ at 1280 px with the side panel: today's head shows its chips on one row.
- Open a note of about 200 KB with tables, code blocks and Mermaid diagrams and type a sentence in the middle: no delay per key; in the Task Manager the CPU of Arcalo and its WebView2 processes falls back to near 0 % right after typing stops.
- In the same note press Ctrl+Shift+M several times: the source view appears at once, the visual editor takes about as long as opening the note; type in the source view: no delay per key, the word count follows after a short pause.
- Close the tab of that note: it closes at once.
- A long note with a `[TOC]`: edit a heading, the table of contents follows; type in a paragraph, it stays as it is.
- Graph view in a large workspace: nodes, links, colors by folder and the filters work as before; Issues (Jira): the list, the search (also by words of the description) and an opened issue with its description and last comments.
- Create a project in Projekte, then open Zeiterfassung in a new tab and add an entry: the new project is in the list.
