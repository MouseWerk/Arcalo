Arcalo 1.21.1

## Improved

- Transcription errors and messages from the speech recognition appear in „Einstellungen → Protokoll“ (never the transcript itself).
- A change Outlook refuses (now part of a series, a meeting from someone else, gone from Outlook) waits with its reason as „Outlook hat die Änderung abgelehnt“ instead of being retried endlessly or dropped; „Änderung verwerfen“ shows the appointment as Outlook has it again.
- When the Git server refuses an upload (a file over 100 MB, a secret found by push protection, a protected branch), the sync shows the server's reason instead of “nothing to commit”.

## Fixed

- Voice notes are transcribed reliably again: the speech recognition no longer stops at random with „Kein Transkript: … Error code: -6“, and „Abbrechen“ stops a running transcription.
- On processors without AVX2 (older or low-cost laptops) the app no longer closes during „Transkribieren“; the voice note names what the processor lacks and keeps the recording.
- A microphone without permission is named: the voice bar shows „Bisher nur Stille …“ with where to allow access, and a microphone that does not answer is no longer reported as „Kein Mikrofon gefunden“.
- A double click while a recording starts no longer leaves a second recording running; quitting while recording asks first and keeps the recording; after a crash the page no longer shows „Transkription läuft …“ forever and no second voice note is offered.
- Recordings of an hour and more need far less memory.
- With a drawing or a PDF open, the lock screen accepts the PIN again; the drawing's last strokes are saved before locking, quitting or an update.
- A save that failed after a newer one succeeded no longer overwrites the newer text.
- A backslash before characters such as „(“, „$“ or „%“, indented text pasted with „Als Text einfügen“, link texts with „]“ and headings ending in „#“ are kept when a page is saved and reopened.
- Find & Replace replaces the right text after characters such as „İ“.
- „Duplizieren“ and „Markdown kopieren“ in the sidebar include what was typed a moment ago; naming a new folder right after creating a page no longer loses the name field.
- Search, tag lists and the chat history no longer show results of an earlier query.
- „Rückgängig“ for a settings change no longer undoes a theme or language changed meanwhile.
- In „Neuer Termin“, Enter right after typing a time or date uses that time; appointments brought back with „Rückgängig“ while Outlook was closed can be changed again; appointments longer than 14 days can be renamed.
- A calendar sync no longer overtakes a change that is still being written; appointments in another own calendar (PST file or second mailbox) are found, deleted into that calendar's own „Gelöschte Elemente“ and opened with „In Outlook öffnen“.
- A paused timer no longer counts its pauses in today's booked time, the week, the „Gleitzeitsaldo“ and the day review.
- The week number („KW“) is right when weeks start on Sunday; applying „Woche vorschlagen“ twice no longer books anything twice.
- Git sync: a long first sync or a large upload over a slow connection is only stopped when the transfer stalls; attached text files such as a CSV from Excel keep their exact bytes and a new computer keeps no second copy; a note whose name differs only by upper and lower case is no longer lost on Linux; your own git hooks and git settings in the environment no longer interfere.
- The additional root certificate („Zusätzliches Stammzertifikat“) under Settings → „Netzwerk“ now reaches the Git sync on Windows.
- An update source on a web server can no longer point downloads at a network share or a local file.
- A capture saved while earlier captures were being retried is no longer lost.
- Moving the data folder takes everything along: the password-protected key, waiting captures, a pending restore or encryption switch, the backup destinations and unfinished recordings.
- A data folder move, a restore or an encryption switch at start no longer runs while an `arcalo` command works on the workspace: Arcalo waits up to 30 seconds or postpones it with a notice.
- Links written the way macOS writes file names (a decomposed „ü“) find their page, show as backlinks and follow renames; following one no longer creates „Müller 2“.
- A note whose front matter nests lists extremely deeply no longer crashes Arcalo.
- Opening today's daily note while an `arcalo` command creates it no longer fails; a key file asking for an excessive cost no longer hangs the password prompt; a restored backup is fully on disk before it replaces the database.
- The assistant's system tools run once and exactly as approved, its git tool only lists branches, and the log hides passwords and keys in quoted values and key= parameters completely.

## Checklist for Windows (manual)

- Record about a minute and transcribe it with Small: the transcript appears (no „Error code: -6“); start another and press „Abbrechen“: „Transkription abgebrochen.“
- Turn off microphone access for desktop apps in Windows settings and record: the voice bar shows the hint. Quit while recording: Arcalo asks, and the recording is offered at the next start.
- Behind a proxy that inspects HTTPS, with its root CA set as „Zusätzliches Stammzertifikat“: „Verbindung testen“ and a Git sync succeed.
- Attach a CSV saved by Excel, sync, and open it on a second computer: the file is byte-identical.
- In an own Outlook calendar in a PST file: change, delete, undo and „In Outlook öffnen“ an appointment.
- Open a drawing, then lock Arcalo: the PIN can be typed and the drawing is saved.
