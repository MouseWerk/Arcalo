Annalo 1.0.1

## Fixed

- **LiteLLM: "No deployments available for selected model"**. The app no longer sends a model the server does not offer (for example the placeholder names of the Lokal/Reasoning tiers). It switches to a configured model the server has. If a model is cooling down on the server, it retries once on another one. Otherwise it explains what is wrong. Private content (#privat, "nur lokal") never leaves the local model. Settings → KI & LiteLLM warns about missing models and offers "Automatisch zuordnen".
- **Zeiterfassung and Einstellungen in narrow windows** (split view, side panel): nothing is cut off, squeezed or overlapping any more.
  - The settings menu becomes a bar at the top.
  - Rows move their control below the text.
  - Dropdowns show their full value ("Nicht runden" instead of "Nicht r").
  - Entries use two lines.
  - The week table scrolls with the first column pinned.
- **Projekte**: process names keep their room, and the table scrolls sideways in narrow panes.
- **Start page**: the Timer widget no longer overlaps the Budgets widget.

## New

- **Startup animation**: the Annalo logo draws itself while the app starts. You can turn it off under Settings → Darstellung.
- **Developer log**: errors (app, AI, Git sync, backups, updates) go to a log file and appear under Settings → Protokoll, where you can filter, copy, clear or open the folder. "Über" shows the number of errors in the last 7 days. Secrets never appear in the log.
- **Windows**:
  - An own title bar with the tabs at the top edge, like Obsidian. You can switch back to the system title bar under Darstellung.
  - A taskbar jump list: Heutige Notiz, Neue Seite, Schnellerfassung, Suchen, Timer, and the recently edited pages.
