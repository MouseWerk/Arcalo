Arcalo 1.23.0

## Improved

- Large Obsidian vaults with many images of the same name import in seconds, and the app stays usable meanwhile.
- „Anhänge verwalten“ opens quickly also with thousands of files; merging a long note no longer takes seconds and gigabytes of memory.
- The calendar names months short in narrow panes; the issue view and lists keep steady rows and fit narrow panes.
- The phone app fits a 360 dp screen, its tab bar makes room for the keyboard, and quick capture keeps its text on Back.

## Fixed

- Git sync: deleting a page with its subpages, moving a subpage out of a page deleted later, or the first subpage of an empty page no longer stops later syncs or sends pages to the trash.
- Git sync keeps titles a file name cannot hold, links to pages renamed on the other computer, and the strokes of a drawing renamed there.
- Changes to neighbouring lines or different properties on two computers are merged instead of one being undone; a page renamed while its conflict was open no longer becomes two pages.
- A second computer no longer creates a second daily note, meeting note or prep page, and no longer removes the other computer's time sheets from the server.
- Files listed in your global Git ignore are synced; a file the server refused no longer blocks every later sync.
- A backup of a newer Arcalo no longer stops every start after a restore, and a restored backup brings back the images of its pages.
- After two failed starts, the return to the previous version no longer acts on updates it cannot undo, and Git sync no longer pushes the old state to every computer.
- Work done after a refused encryption switch is kept, and quick capture text is no longer written unencrypted next to an encrypted database.
- A setting you switch on no longer flips back off, and a settings change from another computer no longer hangs the app.
- Editing keeps Markdown as written: `C++`, `a == b`, letter and roman-numeral lists, numbered tasks, backslashes and indented lines at line ends.
- Code, quotes, callouts, tables and tabs inside list items no longer shift, nest deeper or gain escapes on every save; a task's second line stays in the task.
- `- [ ] ` and `[[Seite]]` typed in full become a task and a link; `/Hinweisbox` and `/Warnbox` work in list items.
- Lists from Word and Outlook, single Excel cells and web tables paste correctly; copied images keep size and caption and paste into other programs.
- A canvas open in two panes no longer undoes the other pane's changes; a title typed right before Ctrl+W is kept; an open page follows a rename made elsewhere.
- Obsidian imports: links and embeds with a path open the imported note and file, a note next to a folder of its files is imported, and a bare embed shows the image of its own folder.
- Markdown export links to titles with `:`, `/` or `?` work, and a Markdown copy imported back keeps its pages and titles; HTML export keeps Markdown images.
- `/zeit` across a clock change books the real length, and a booking written later in an earlier daily note lands on that day.
- Focus sessions no longer round up once per session, and undoing a deleted focus block restores its booking.
- Changing the target hours no longer changes past months; weeks starting on Sunday are counted correctly; due dates no longer show the day before west of UTC.
- Recurring tasks on the 29th to 31st and yearly tasks keep their dates; queries with `status!=offen` are correct and no longer list templates or folders; tasks in code blocks are no longer tasks.
- A cut-off calendar download no longer empties the calendar; Outlook all-day appointments stay all-day; holidays and short Fridays are no longer marked as missed.
- „Heute“ and open task views move on after midnight; `/time` accepts dates with slashes.
- Jira worklogs are never posted twice or lost, also after edits, retries, deletions or two equal bookings.
- Jira issues moved to another project or deleted are followed: they stay in lists, their tasks get ticked, and notes, backlinks and hours move along.
- The sprint widget counts more than 50 issues, estimates are sent in Jira's format, and attachments of the same name no longer overwrite each other.
- Text of `#privat` pages no longer goes to cloud models in status reports, the morning briefing, bookings or search.
- An AI answer can no longer send data to another server through an image or styles, and links the app does not handle no longer replace its window.
- AI chat: stopping, deleting, retrying or opening a chat in its own window during an answer no longer loses questions or leaves empty turns; removing a provider and undoing it keeps its API key.
- Command palette and quick search open the hit you chose, keep the selection steady and are ready to type at once.
- Presentations keep image sizes, wrap code, show Mermaid readably, follow the note and the theme, and keys no longer edit the note.
- Excalidraw drawings accept typing in their dialogs, open links outside the app, and Esc in a field keeps the editor open.
- A booking made on the phone no longer replaces a desktop booking of the same day.
- `arcalo export --mark` exports only new bookings in the settings' layout and marks them only after writing; `timer start` and `time edit` reject unknown Vorgänge and Leistungsarten.
- Dropdowns stay in place while the page moves and close when you scroll; dialogs focus their first field also when the form loads late.

## Checklist for Windows (manual)

- Sync with Git between two computers: delete a page with subpages on one, rename a page on the other, sync both: no pages in the trash, links intact.
- Import an Obsidian vault with path links (`[[Ordner/Notiz]]`) and images in subfolders: links open the notes, images show.
- Paste a list from Word and a table from a web page into a note, save, reopen: unchanged.
- Book `/zeit` in a daily note and a focus session, then undo deleting the focus block: hours are correct.
- Open a Jira issue, log work, edit it and sync twice: one worklog in Jira.
- With a `#privat` page and a cloud model, create a status report: the private text is not in it.
- Start a presentation from a note with images and code: sizes kept, keys do not change the note.
- Restore a backup and restart twice: Arcalo starts and the images are there.
