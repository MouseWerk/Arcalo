Arcalo 1.11.0

## Improved

## Fixed

- Follow-up mail through the mail program: attendees of calendar files (ICS) given with a name and an address are in the `mailto:` link too, not only those given as a bare address; the Outlook draft gets name and address. Calendar, notes and prep pages still show the name.
- Kalender: focus blocks show in the month view and in the list, with their time; a click opens the block's detail.
- „Im Kalender planen…“ looks for free slots inside the working hours of Settings → Zeiterfassung → Arbeitszeit („Arbeitszeit von – bis“, default 08:00–18:00) instead of a fixed 08:00–18:00.
- Local graph: labels of nodes near the edge of the panel stay inside it (shortened only when wider than the panel).
- The start page's random note shows the text of a canvas' cards, not its JSON.
- A page opened with a generated part at the top (meeting prep, status report) no longer starts with the part's start marker selected.
- Unlinked mentions skip HTML comments over several lines, not only their first line.
- „Rückgängig“ after merging duplicates keeps edits made to the kept page after the merge where they do not collide with the merged part.
- Links and embeds in table cells (`[[Seite\|Alias]]`, `![[bild.png\|200]]`, as the editor writes them) count as backlinks, are renamed with their page, and their attachments are no longer reported as unused. Code blocks fenced with `~~~` are code for links and tasks too (all pages are indexed once after the update).
- Page titles that are Windows device names (`CON`, `NUL.txt`, `COM1`, `LPT¹`) get a safe file name in the Markdown copy (`CON_.md`, `NUL_.txt.md`; before, `NUL.txt_.md` was still a device name). Very long titles in Chinese, Japanese or with emoji no longer exceed the 255 bytes Linux and macOS allow per file name.
- Titles with a decomposed umlaut (file names from macOS, `u` plus combining diaeresis) are stored composed, so `[[Müller]]` finds the page and two pages „Müller“ no longer share one mirror file.
- Git sync: notes deep in folders work with Git for Windows (long paths), and file names with umlauts from macOS arrive composed.
- Quick links to `file://server/share/…` open the network share, and escaped names (`%C3%BC`) open the right file.
- Timer: when the computer slept while a timer ran, the time asleep counts as a pause (offered for subtraction when the timer stops) also where the system's idle time does not include it.
- CATS export: the hours of a day add up to its booked time (three times 20 minutes are 0,33 + 0,34 + 0,33 = 1,00 h, not 0,99 h).
- Due dates without a year that have passed („bis 5.1.“ in December) are next year's, as in voice notes.
- A Jira worklog deleted in Jira is posted again when its entry changes, instead of failing every hour.
- A calendar file with an absurd length (`DURATION:P999999999999D`) or a broken time zone offset no longer stops the calendar sync.
- A few buttons whose action failed (pause the update download, open quick capture, ignore a duplicate, retry backup destinations, load activity types) now show an error.
- The random note of the start page changes on the day after the change to summer time too (both days had the same).

## Checklist for Windows (manual)

- [ ] Create pages „CON“, „nul.txt“, „COM1“ and „Aux.Notizen“; make a backup with the Markdown copy on: the folder holds `CON_.md`, `nul_.txt.md`, `COM1_.md`, `Aux_.Notizen.md`, each opens in Explorer and Notepad, and the Git sync pushes them.
- [ ] A page nested eight folders deep with long titles (full path over 260 characters): the Markdown copy writes it and the Git sync commits and pushes it without „Filename too long“.
- [ ] A quick link `file://<server>/<share>/<Ordner mit Umlaut>` opens the share's folder in Explorer.
- [ ] Follow-up mail of a meeting from an ICS calendar with named attendees: the Outlook draft resolves every attendee, and „Im Mailprogramm öffnen“ fills To with their addresses.
