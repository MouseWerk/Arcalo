Arcalo 1.18.0

## Improved

- Arcalo has a full command line: the program you start the app with also runs commands, for example `arcalo pages show "Weekly sync"`, `arcalo tasks add "Angebot schicken" --page "Kunde Müller" --due tomorrow`, `arcalo daily append "…"` or `arcalo time week`. It covers pages (create, show, append, replace, properties, rename with links, move, duplicate, trash, restore, delete for good, versions, links), daily notes, tasks, tags, search, the calendar, time entries, absences, projects, attachments, the trash and the settings. The commands of earlier versions (`zeit`, `timer`, `project`, `export`, …) work as before.
- Made for scripts and AI agents with a terminal: with `--json` every command prints JSON, errors come with a clear exit code, and pages can be named by id, title or path. The documentation (docs/cli.md) explains how to point an AI agent at it.
- The command line works on the same workspace as the app, found the way the app finds it (also a chosen data folder, a portable copy and an encrypted workspace, whose key it reads from the credential store).
- While the app is open, it shows what the command line changed within a second, without a restart: new pages in the tree, text and tasks in an open note, the task list, bookings, projects and settings. Text you are typing in an open note is never lost, and every change the command line makes to a note can be taken back under „Versionen“.
- `arcalo` works in every new terminal: the Windows installer puts the program folder on your user PATH (an update keeps one entry, uninstalling removes it, the rest of your PATH stays as it is). On macOS, Settings → Desktop → „Befehlszeile“ makes the command available after asking for your password; on Windows the same switch takes it off again or puts a portable copy on the PATH.
- A note you are editing no longer overwrites a change made at the same moment elsewhere (a task ticked off in Aufgaben, a booking's chip, the command line): both changes are kept.

## Fixed

- Two writes to the workspace at the same moment (the app and another program on the same data folder) no longer fail with „database is locked“: the second one waits for the first.

## Checklist for Windows (manual)

- PATH: install 1.18 over 1.17, open a new PowerShell window: `arcalo info | Out-String` works; `$env:Path -split ';' | Select-String Arcalo` shows the program folder once. Install 1.18 again (and let the app update itself once a newer build exists): still exactly one entry. In `regedit` → `HKEY_CURRENT_USER\Environment` the value `Path` keeps its type `REG_EXPAND_SZ` and entries such as `%USERPROFILE%\...` stay unexpanded.
- PATH, long value: in regedit, make `HKEY_CURRENT_USER\Environment\Path` longer than 8,192 characters (append `;C:\x1`, `;C:\x2`, … entries) and save its text to a file, then install 1.18: the old text is unchanged, only `;<install folder>` is appended. Uninstall: the value is exactly the saved text again.
- PATH, settings: Settings → Desktop → „Befehlszeile“ shows the switch on. Switch it off: a new terminal no longer finds `arcalo`; install the update again: it stays off. Switch it on: back again. Silent install (`Arcalo_1.18.0_x64-setup.exe /S`) adds the entry as well; the machine Path (`HKEY_LOCAL_MACHINE\...\Environment`) is never touched.
- PATH, uninstall: Apps → Arcalo → uninstall: a new terminal no longer finds `arcalo`, the other `Path` entries are all still there. The portable ZIP changes nothing until its switch is turned on; turning it off again removes its folder.
- Install 1.18, start Arcalo once, close it. In PowerShell: `& "$env:LOCALAPPDATA\Arcalo\arcalo.exe" --json info | Out-String`: prints the data folder `%APPDATA%\de.mousewerk.arcalo` and the number of pages, no window opens. `& "$env:LOCALAPPDATA\Arcalo\arcalo.exe" --help | Out-String` lists the commands in English.
- Without a command (Start menu, desktop shortcut, autostart with `--minimized`, a jump list entry, a notification button) Arcalo starts as before.
- With Arcalo open on a note: `arcalo.exe pages append "<that note>" "Zeile aus PowerShell" | Out-String`: the line appears in the open note within a second. Type a sentence in the note and right away run the command again with another line: after the autosave the note holds both, each once.
- `arcalo.exe pages create "Aus PowerShell" --body "Hallo" | Out-String`: the page appears in the tree; `arcalo.exe tasks add "Rückruf" --page "Aus PowerShell" --due tomorrow | Out-String`: the task shows in the note and under Aufgaben (Ctrl+Shift+A).
- Encrypted workspace (Settings → Sicherheit → „Datenbank verschlüsseln“, restart): `arcalo.exe --json pages list | Out-String` lists the pages (the key comes from the Windows Credential Manager). In another Windows user account the same command against that data folder (`--data-dir`) fails with a message about the missing key and exit code 4 (`$LASTEXITCODE`).
- Portable ZIP: unpack, start `Arcalo.exe` once and create a page, close it; `.\Arcalo.exe --json pages list | Out-String` in that folder lists the page from `data`, not the installed copy's.
- Microsoft Store build: `Arcalo.exe --json info | Out-String` from any folder (the app execution alias) prints the Store copy's data folder.
- Settings → Sicherung → „Speicherort ändern…“ to another folder and restart: `arcalo.exe --json info | Out-String` names the new folder. Choose yet another folder but do not restart: the command line still uses the current one.
- In the command prompt (cmd): `start /wait /b arcalo.exe pages show "Gibt es nicht"` shows „Fehler: Seite „Gibt es nicht“ nicht gefunden“, and `echo %ERRORLEVEL%` then prints 2. Without `start /wait` the prompt may come back before the message, as for any windowed program.
