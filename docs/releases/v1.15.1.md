Arcalo 1.15.1

## Improved

## Fixed

- Ticking off a repeating task closed the app when the text after the ✅ marker had an umlaut, emoji or a second ✅ near its start (for example `✅ erledigt äh`). The task is ticked off and its next date added as usual.
- After a discarded change of the data location (Einstellungen → Über → „Speicherort ändern“, then „Verwerfen“) or a data folder move that did not finish in an earlier version, 1.15.0 kept working in the data folder of the old name, copied the whole data folder again at every start and showed „Daten der älteren Version übernommen“ each time. 1.15.1 takes the latest state over once and then works in the new folder. Folders named `de.mousewerk.arcalo.<date>-<time>` next to the data folder that 1.15.0 left at each start hold older copies only and can be deleted.
- „Verwerfen“ of a changed data location no longer writes the standard data folder as a fixed path.

## Checklist for Windows (manual)

- With 1.14.1: Settings → Über → „Speicherort ändern“, choose another folder, then „Verwerfen“. Update to 1.15.1 (setup over it): Arcalo starts once with „Daten der älteren Version übernommen“ or without notice, Settings → Über shows `%APPDATA%\de.mousewerk.arcalo`; restart twice: no notice, and no new `de.mousewerk.arcalo.<date>` folder appears in `%APPDATA%`.
- Same from 1.15.0 on a computer that showed the notice at every start: after the update to 1.15.1 the notes written in 1.15.0 are there, the notice comes once more and then no more.
- A task `- [ ] Test every:weekly due:2026-10-05 ✅ erledigt äh` ticked off on the start page and in the tasks view: no crash, a new open line with the next date appears.
