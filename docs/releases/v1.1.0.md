Annalo 1.1.0

## New

- **Drawings**: type `/Zeichnung` (or "Neue Zeichnung einfügen" in Ctrl K) for an Excalidraw whiteboard inside the note.
  - Shapes, arrows that stay attached, text, frames, images and a shape library, in German.
  - Saves by itself. It is stored as `attachments/<name>.excalidraw` with an SVG preview and embedded as `![[name.excalidraw]]`, so the Obsidian Excalidraw plugin reads it too.
  - Click the preview to keep drawing. Works offline.
- **Editor toolbar** above every note (can be turned off under Settings → Editor → Werkzeugleiste):
  - Undo/redo, text and headings, bold, italic, strikethrough, highlight, code.
  - Web and page links, lists, task lists, quotes, code blocks.
  - Einfügen: every slash command. KI: the inline assistant.
  - In narrow panes it shows icons only.
- **Editor tools**:
  - Find and replace (Ctrl+H): replace one or all.
  - Change case: UPPER, lower or Title.
  - Sort lines A–Z or Z–A; remove duplicate lines.
  - Move a block with Alt+Up/Down.
  - Insert date and time; remove formatting.
  - Statistics: words, characters, reading time.
- **Assistant suggestions** come from what is going on: the open page, its Vorgang's budget, overdue tasks, gaps in this week's bookings, and the time of day. Every answer offers the follow-ups Kürzer, Als Stichpunkte, Als Tabelle and Auf Englisch.
- **Right-click in the chat**:
  - Copy an answer as Markdown or text, or quote it.
  - Append an answer to the open page, or save it as a new page.
  - Regenerate an answer, or ask a follow-up.
  - Edit or resend a question.
- **Right-click on images**:
  - View full screen.
  - Size: small, medium, large or original.
  - Open, or show in the folder.
  - Copy the image or its embed.
  - Remove it from the note.
- **File explorer menu**:
  - New page beside, subpage, or subpage from a template.
  - Duplicate a page.
  - Change its icon.
  - Move it up, down, one level higher or to the top level.
  - Copy its link, title or Markdown.
  - Expand or collapse all subpages.
- **Tabs**:
  - Move left or right, or to the other pane.
  - Duplicate a tab.
  - Close the tabs to the right.
  - The active tab always scrolls into view, and the mouse wheel scrolls the tab bar.

## Fixed

- **Submenus in context menus** (for example Groß-/Kleinschreibung) did not open. They now open by hover, click or arrow keys.
- **Dragging tabs**:
  - Dropping a tab after the last tab works.
  - You can drop a tab onto another pane.
  - A marker shows where it will land.
- **Tooltips** (for example on the + in the file explorer) are no longer hidden under the editor.
