Annalo 1.4.1

## New

- **Kalender**: a new page (ribbon, Ctrl+Shift+E or „Kalender öffnen“ in the palette) shows your meetings next to the time you booked. Day, work week, week, month and a list, with calendar weeks, the current time, overlapping meetings side by side and your bookings as a lane beside them. Each day's header shows its daily note, due tasks and booked hours.
- **Book a meeting with one click**: click a meeting and choose „Zeit buchen“. The entry opens filled in with the day, start, length and subject. For a meeting you booked before (the same series or the same subject) Annalo suggests the same Netzplan and Vorgang. Booked meetings get a check mark; meetings you do not want to book can be marked „Nicht buchen“.
- **Meeting notes from the calendar**: „Besprechungsnotiz“ creates a page below „Besprechungen“ with date, time, place, organizer, attendees and the Teams or Zoom link. If you have a template „Besprechung“ in „Vorlagen“, it is used.
- **Outlook Classic**: under Einstellungen → Kalender switch on „Outlook-Kalender lesen“. Annalo reads the default calendar of the Outlook on your Windows computer directly, without admin rights and without any app registration. Outlook should be set up and not run as administrator. If Outlook asks whether a program may access e-mail address information, allow it. The new Outlook does not allow this; use an ICS address instead.
- **ICS calendars**: under Einstellungen → Kalender choose „ICS-Adresse abonnieren“ and paste the address of a published calendar. In Outlook on the web: Einstellungen → Kalender → Freigegebene Kalender → „Kalender veröffentlichen“, then copy the ICS link. Google Calendar: the „Privatadresse im iCal-Format“ of a calendar. You can also add an `.ics` file („.ics-Datei einbinden“); it is read again on every sync. Repeating meetings, changed or cancelled single meetings and Windows time zones are handled.
- **Private and secure**: calendars sync in the background every 15 minutes (adjustable), and „Jetzt synchronisieren“ does it at once. Subscription addresses often contain a secret key, so they are stored in the Windows Credential Manager or the macOS Keychain, not in the settings. Private appointments show only „Privater Termin“ and their time unless you allow more, the text of appointments is not kept unless you switch it on, and the assistant does not see your calendar.
- **Termine on the start page and in the timesheet**: the start page widget „Termine“ lists today's meetings, and the timesheet shows „Termine übernehmen“ with this week's meetings that are not booked yet, each with „Buchen“.

## Fixed

- **Links to files**: `[[Angebot.pdf]]`, `[[Ordner/Angebot.pdf]]` and `[[Angebot.pdf|das Angebot]]` are shown as file links with the file's icon and open the file like an attached file (PDFs in the viewer, other files in their program). They no longer count as missing pages in the links panel, and a click never creates a page. A linked file that is not in the attachments is marked as missing. A page whose title looks like a file name (`[[Node.js]]`) stays a page link.
- **Error messages name the file**: problems with attachments, exports, the Markdown copy, vault import and export, backups, drawings and moving the data folder now say which file or folder is affected, for example „Datei nicht gefunden: C:\…\attachments\Angebot.pdf“ or „Keine Berechtigung für den Ordner …“. Long paths are shortened in the middle in the message; the developer log keeps the full path.
- **Start-up problems**: a database from a newer Annalo version is left exactly as it is, and quitting from the start-up dialog ends Annalo with an error code. The dialog's text is written to the developer log.
- **Code on slides**: code blocks in presentations and in the presenter view have the same syntax colors as in the editor, also for languages that load on demand. On white Beamer slides in a dark theme the code uses light-background colors.
- **Tabs show long titles**: a tab grows up to 360 px to show its whole title while the tab bar has room. When space gets tight, short titles still stay whole and long ones are shortened first.
