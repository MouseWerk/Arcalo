Annalo 1.2.0

## New

- **Files in notes**: drag any file from Explorer or Finder into a note, paste it, or type `/Datei einfügen`.
  - PDF, Word, Excel, PowerPoint, archives and more, up to 100 MB. The file is copied to `attachments/` and embedded as `![[Angebot.pdf]]`, as in Obsidian.
  - Other files show as a chip with type, name and size. Click it to open the file in its app. Right-click: open, show in the folder, copy the embed, remove from the note.
  - Programs and scripts are never started from a note; "Öffnen" shows them in the folder.
  - Vault import and export and the Markdown copy take the files along.
- **PDF viewer**: a PDF in a note shows its first page. Click it to read the whole PDF inside Annalo, with pages, zoom, search and "Extern öffnen". Works offline.
- **Full width and Markdown source**, next to the star:
  - "Volle Breite" (Ctrl+Shift+L) lets the text use the whole pane.
  - "Markdown-Quelltext" (Ctrl+Shift+M) shows the note's file as it is; Tab indents and Enter continues lists.
  - Both are remembered per page.
- **Links in the ribbon**: your links now sit in the left bar below Zeiterfassung, Aufgaben and Projekte, one icon each with the name as tooltip. Right-click to open, edit, move, add or remove.
- **Editor toolbar in the header row** above the page title, in place of the small page title.
- **Inline AI on an empty line** writes new text there, with the page as context: Weiterschreiben, Gliederung, Aufgaben ableiten, Zusammenfassung, Nächste Schritte, or your own instruction.

## Fixed

- **KI chat** failed while the meeting summary worked.
  - Models or LiteLLM setups that do not accept tools or a temperature are now asked again without them.
  - A model whose backend is down (for example a local Ollama that is not running) hands over to another configured model.
  - Tool calls without an ID (Ollama, Gemini) work.
  - A slow embedding model no longer holds up the answer.
- **Windows start**: the window appears only once the start screen is drawn. There is no unstyled page or white flash before the logo any more.
- **Inline AI bar**: near the bottom of the window it opens above the text and stays in view while the answer comes in.
- **Tabs** of pages created elsewhere (for example from the task list) showed "Seite" instead of the title.
