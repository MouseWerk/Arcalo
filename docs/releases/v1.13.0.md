Arcalo 1.13.0

## Improved

- The developer log is now called `arcalo.log` (and `arcalo.jsonl`) in the data folder; the log files of earlier versions are renamed at the first start. The log level variable is `ARCALO_LOG` (`ANNALO_LOG` still works).
- Removing a booked `/zeit` chip in the Markdown source view now removes its booking like the normal editor does: the same toast with „Rückgängig“, the booking goes only when the toast closes, undo in the text brings it back, exported bookings stay, and a chip cut and pasted into another note keeps its booking.

## Fixed

- The start-up animation spelled the old name „Annalo“ under the logo; it now shows „Arcalo“.
- Git sync commits of an existing workspace that still used the old default author „Annalo <annalo@localhost>“ now use „Arcalo <arcalo@localhost>“ (an author you entered yourself stays).
- The Windows installer's details list no longer names „Annalo“ when it updates an installation from before 1.7.
- A booking that came back after its chip was removed (undo after the toast closed, or „Erneut buchen“ on a chip marked deleted) lost its Jira worklog link; it now keeps its worklog (a pending deletion in Jira is cancelled) or, if Jira already deleted it, posts it once more, so Jira never ends up with a duplicate or an orphaned worklog.

## Checklist for Windows (manual)

- Start Arcalo with the start-up animation on (Settings → Darstellung → Startanimation): the logo draws itself and „Arcalo“ appears under it.
- Update an installation of 1.12 with the 1.13 installer and open „Details anzeigen“: no line names „Annalo“; Settings → Protokoll → „Ordner öffnen“ shows `arcalo.log` (the earlier `annalo.log` renamed).
- In a note, book `/zeit 1h PROJ-123 Test` on a Jira issue (Settings → Jira, „Arbeit auch in Jira protokollieren“ on), switch to the Markdown source view (Ctrl+Shift+M), delete the chip's line and wait for the toast to close: the booking is gone from Zeiterfassung. Press Ctrl+Z in the text: the booking is back, and Jira shows exactly one worklog for it.
