Arcalo 1.13.0

## Improved

- A page keeps the Markdown it was written in: a page you open and save without editing stays byte-identical, and an edited block keeps its style (`*` or `+` bullets, `1)` numbering, tab-indented lists, `~~~` and longer code fences, `_kursiv_` and `__fett__`, `Titel` over `===`, `***` rules, reference links `[Text][ref]` with their definitions, `<https://…>` links, unpadded tables, Windows line ends). Notes from Obsidian, GitHub or VS Code no longer show changes on every line after an edit.
- Hovering a link to a section (`[[Seite#Abschnitt]]`, `[[Seite#^id]]`, `[[#Abschnitt]]`) previews that section instead of the start of the page; a click on the card's title opens the page there.
- „Als HTML-Datei teilen“: headings get stable anchors from their text (`#page-12-ziele`), and `[[#Abschnitt]]`, `[[#^id]]` and section links to pages in the file jump to the section inside the file.
- The developer log is now called `arcalo.log` (and `arcalo.jsonl`) in the data folder; the log files of earlier versions are renamed at the first start. The log level variable is `ARCALO_LOG` (`ANNALO_LOG` still works).
- Removing a booked `/zeit` chip in the Markdown source view now removes its booking like the normal editor does: the same toast with „Rückgängig“, the booking goes only when the toast closes, undo in the text brings it back, exported bookings stay, and a chip cut and pasted into another note keeps its booking.
- Pin tabs: right-click a tab → „Tab anheften“ (or the command palette, or a shortcut you set in Settings → Tastatur). Pinned tabs stay at the left in a compact form, keep their place when you open other pages, survive a restart and split panes, and „Andere Tabs schließen“ and the new „Alle Tabs schließen“ leave them open.
- Rename a page or folder right in the page tree: F2 or a double click on its name, Enter saves (links to it are updated), Escape cancels; an empty or taken name is explained under the field, and the toast offers „Rückgängig“.
- The Projekte table in a narrow pane shows that more columns follow (a shadow and a small arrow button at the edge) and scrolls with the arrow keys; in a very narrow pane the name column leaves room for the others.
- The side panel's views (Assistent, Gliederung, Links, Graph) are one stop for the Tab key; the arrow keys, Home and End switch between them.

## Fixed

- A link around an image (`[![Badge](…)](…)`, as in GitHub READMEs) and bold or italic around a wiki link (`**[[Seite]]**`) were lost on save.
- A link whose text equals its target (`[INSTALL.md](INSTALL.md)`) became plain text on save.
- Subtasks indented with a tab (Obsidian's default) lost their first characters on save (`\t- [ ] Teil` became `[ ] Teil`).
- A code block whose fence is indented by one to three spaces became an ordinary paragraph.
- Escaped stars (`\*\*nicht fett\*\*`) were saved so that the text turned italic.
- The start-up animation spelled the old name „Annalo“ under the logo; it now shows „Arcalo“.
- Git sync commits of an existing workspace that still used the old default author „Annalo <annalo@localhost>“ now use „Arcalo <arcalo@localhost>“ (an author you entered yourself stays).
- The Windows installer's details list no longer names „Annalo“ when it updates an installation from before 1.7.
- A booking that came back after its chip was removed (undo after the toast closed, or „Erneut buchen“ on a chip marked deleted) lost its Jira worklog link; it now keeps its worklog (a pending deletion in Jira is cancelled) or, if Jira already deleted it, posts it once more, so Jira never ends up with a duplicate or an orphaned worklog.
- The Projekte table scrolled sideways by a few pixels even in a wide window (the row buttons did not fit their column).

## Checklist for Windows (manual)

- Open a note written in Obsidian (tab-indented tasks, `*` bullets) and one GitHub README in Arcalo, change one word, then compare the files in Git or a diff tool: only that line changed.
- Hover a `[[Seite#Abschnitt]]` link: the card shows that section with „Seite › Abschnitt“ as its title.
- Start Arcalo with the start-up animation on (Settings → Darstellung → Startanimation): the logo draws itself and „Arcalo“ appears under it.
- Update an installation of 1.12 with the 1.13 installer and open „Details anzeigen“: no line names „Annalo“; Settings → Protokoll → „Ordner öffnen“ shows `arcalo.log` (the earlier `annalo.log` renamed).
- In a note, book `/zeit 1h PROJ-123 Test` on a Jira issue (Settings → Jira, „Arbeit auch in Jira protokollieren“ on), switch to the Markdown source view (Ctrl+Shift+M), delete the chip's line and wait for the toast to close: the booking is gone from Zeiterfassung. Press Ctrl+Z in the text: the booking is back, and Jira shows exactly one worklog for it.
- Pin two tabs, open a split pane, restart Arcalo: the pinned tabs are back at the left of their panes; „Alle Tabs schließen“ leaves them open.
- In the page tree press F2 on a page that other pages link to, type a new name, Enter: the page stays closed, the links show the new name, „Rückgängig“ in the toast restores both.
