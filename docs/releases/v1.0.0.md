Annalo 1.0.0: the first release

Notes, time tracking and your own AI in one local-first desktop app for Windows, macOS and Linux.

## Highlights

- **Notes like Obsidian**: live-preview Markdown, [[wiki links]] with hover preview, backlinks, tags, tables, tasks with due dates, templates, images, version history with diff, scroll outline, split view with tabs, Obsidian vault import
- **Time tracking for SAP PS**: `/zeit NP-8801/1020 2.5h #DEV …` in any note, autocomplete with remaining plan hours, timer with idle detection, weekly timesheet, export to SAP CATS / Jira / CSV / JSON, projects with budget, EAC and critical path
- **AI on your own LiteLLM server**: assistant with cited sources, inline AI on selected text, meeting summaries with tasks, smart `/zeit` that suggests the Vorgang and asks before it books
- **Start page with widgets**: today's tasks, week hours, budget warnings, recent pages, timer, calendar
- **Desktop**: global quick search (Ctrl Shift O) and quick capture (Ctrl Shift Space), tray icon, reminders, automatic updates
- **Your data stays yours**: one local database, daily backups with a readable Markdown copy, trash, Git sync to your own repository, secrets in the Windows Credential Manager / macOS Keychain
- **Customizable**: themes and accent colors, fonts, German/English, rebindable shortcuts, full proxy support (system, manual, PAC, authentication, company root CA)

## Downloads

- **Windows 10/11**: `Annalo_1.0.0_x64-setup.exe`. Installs per user, no admin rights needed
- **macOS 11+**: `…_aarch64.dmg` (Apple Silicon) or `…_x64.dmg` (Intel). Not notarized: the first time, right-click the app → Öffnen, or run `xattr -cr "/Applications/Annalo.app"`
- **Linux**: `…_amd64.deb` (Debian/Ubuntu) or `…_amd64.AppImage` (any distribution)
