Arcalo 1.16.0

## Improved

- Git sync: a page moved or renamed on one computer (to another parent, by „Aufräumen“, a new title) is moved on the other computer too. It keeps its versions, time entries and links instead of being deleted and created anew, and „Aufräumen“ no longer leaves every moved page twice on both computers.
- Git sync: a page you deleted that another computer edited meanwhile comes back with that edit (from the trash where possible), with a notice.
- A second start of Arcalo on the same data folder now ends with a message also where the usual check does not work (Linux without a session bus).
- Saving a page with thousands of tasks (a paste, a restored version, a pulled note) takes a fraction of a second instead of many seconds, and an edit of a long page no longer rewrites all its tasks.
- The week review, the tag suggestions under the page properties and short searches of one or two letters are much faster on large workspaces; one or two letters find titles and whole words.
- Opening a page waits less: reads such as the page schema, the trash, chats and attachments no longer queue behind saves.
- The first start after an update shows the window sooner; the one-time history of a large workspace is derived in the background.
- The task view and the day review load less data at once.
- Switching tabs keeps each note as you left it: scroll position, cursor and undo history; views keep their filters (for example „Erledigt“ in Aufgaben).
- F6 and Umschalt+F6 jump between ribbon, sidebar, page, side panel and messages, so „Rückgängig“ in a message can be reached from the keyboard.
- Settings → Tastatur lists the fixed keys too (editor, page tree, calendar, focus blocks, start page, graph, command palette).
- On a Mac, find and replace is ⌥⌘F (⌘H hides the app) and the next and previous tab are ⌘⇧] and ⌘⇧[ (⌘⇥ switches apps).
- Screen readers: the slash, link and tag lists say which entry Enter takes, dialogs read their text, calendar events say their day, tables have headers, and buttons in lists say what they act on.
- Splitters between sidebar, page and side panel can be moved with the arrow keys; the editor toolbar is one Tab stop with the arrow keys inside.
- Renaming a page in its title can be undone, as in the page tree; dragging a single page in the tree can be undone too.
- The source view shows when a save failed and uses the autosave delay of Settings → Editor.
- Escape closes the setup („Einrichtung beenden“); answers given so far are kept.
- Hours look the same everywhere: start page, time tracking, reviews, briefing, projects, the calendar and focus sessions follow „Stunden als“ (1,50 h or 1:30 h).
- Shortcut hints name the keys of your keyboard: „Strg“, „Umschalt“, „Eingabe“ and „Entf“ in German tooltips, menus and settings, and Strg+# instead of Ctrl+\ on a German keyboard.
- A new German workspace keeps its daily notes in „Tagesnotizen“; existing workspaces keep their „Journal“.
- Consistent wording: „Computer“ everywhere, error messages that say what failed, one week heading format, „Tagesnotiz eines Tages öffnen“ and „Kalender“ can be told apart, „Zusammenfassen“ in both reviews; in English „Import“ and „Apply“ instead of „take over“, „Time tracking“, „Plan the week's bookings“ and „Mon, Tue, Wed“.
- Text that is cut shows in full as a tooltip (tree, search, calendar, tasks, time entries).
- Meetings show their calendar color as a dot in „Termine buchen“ and on the start page.
- Projekte: the table fits its card; schedule and progress move under the name in narrow windows.
- Kalender: day headers wrap instead of cutting icons; booked time stays readable in narrow columns; month cells keep the meeting titles; the start page timeline shows narrow meetings as color only.
- Start page tasks keep their title readable; the page name gives way first.
- Tag suggestions are quiet gray chips; more than two collapse into „+n weitere“.
- Split panes: page titles scale with the pane, no sideways scrollbars, no half-hidden tabs; time tracking and the daily review keep their buttons compact.
- Mermaid labels sit on the page background; query tables show [[links]] as links with a narrow checkbox column; search snippets keep code like `!==` as written.
- Better contrast: today's date markers, the keyboard focus on the current row and dimmed rows (other months, switched-off calendars, done tasks) reach WCAG AA in all themes.
- The assistant panel shows the AI setup hint only once and no suggestions while no AI is connected.
- A running timer no longer keeps the processor busy: the red dot pulses a few times when the timer starts and then stays still, and only the time itself is updated each second (also for voice recordings and a meeting that is on now).
- Long notes: in the Markdown source view, typing stays fast; the word count follows after a short pause in typing. Typing in long notes in the visual editor no longer lays out the whole note an extra time per key.
- Notes closed in tabs give their memory back, and opening many notes one after another no longer slows Markdown reading down.
- Shortcuts are written one way everywhere: „Strg+Umschalt+D“ in tooltips, menus and hint texts (also „Umschalt+Eingabe“ under the chat), as keys in Settings → Tastatur; the command palette says „Eingabe“ in German.
- Estimated editing times read as estimates: „~35 Min.“ or „~1,25 h“ instead of „~0,57 h“.
- The week and day review name the workdays before Arcalo was set up „vor der Einrichtung“ instead of „kein Arbeitstag“.
- In a narrow pane the reviews show „Als Wochenbericht speichern“ and „In Tagesnotiz übernehmen“ as icons, so „Zusammenfassen“ stays in the row.

## Fixed

- Git sync: pages titled „README“ or below a page „Zeiterfassung“ or „attachments“ never reached the other computer and were removed and added again with every sync.
- Git sync: a page moved on one computer and edited on the other kept only one of the two changes.
- Settings sync: the AI provider and model of each tier, the provider and model of the search by meaning and the prices stay on their computer; a second computer without that provider kept getting them and its assistant stopped working.
- Returning to 1.14 after a failed update to 1.16: 1.14 now knows that 1.16 did not start (it is not offered again) and shows that it returned.
- A secret (access token, API key) changed in 1.14 after returning to it is used again by 1.16.
- A first start of 1.15 or later that could not finish taking over the data of 1.14 no longer hides the notes written in between.
- A timer whose start lies in the future (the computer's clock was set back) can be stopped; the booking is kept without a duration to fill in. Daily backups go on when the newest backup carries a date in the future.
- The password-protected copy of the database key and the window position are written safely: a full disk or a crash while saving no longer damages them.
- A pasted image cut short by a power loss is written again the next time it is pasted.
- Attachments named like Windows devices (`CONIN$.txt`, `COM¹.txt`) are renamed when added, as the Markdown export does.
- The start page counts own weekday targets, public holidays and absences like the time tracking: no „Fehlt 8 h“ on Christmas, on a vacation day or for 8 h on a 5-hour Friday; a Saturday with own hours counts too.
- A new workspace no longer shows the days before its setup as missing hours, in the time tracking, the start page, the week review, the week proposal and the assistant's suggestions alike; the overtime balance starts on that day.
- The start page and the week review no longer disagree about „Lücken“: time between bookings is now „ohne Buchung“; a budget that runs out within two weeks is no longer shown as „Im Plan“.
- A vacation day on a public holiday or a weekend no longer counts against the vacation account.
- Berlin: 8 May 2020 is a public holiday.
- Repeating tasks: „monatlich am 15.“ due on the 10th repeats on the 15th of the same month; a monthly task from the 31st and a yearly one from 29 February keep their day instead of moving to the 28th for good.
- Calendar subscriptions: an all-day series with exceptions or moved days given with a time (Exchange, some CalDAV servers) shows the right days.
- „Aufräumen“ files pages by the local day they were created, and „geändert“ in queries uses the local day: an edit just after midnight counts for that day.
- Search by meaning keeps finding all pages after many edits; edited and deleted passages no longer crowd them out.
- With „KI verwenden“ off or forbidden by your organization, Settings → Netzwerk no longer lists or tests AI providers, and no connection test sends a provider key.
- Error messages appear in English in the English interface (backup copies, calendar range, Outlook, mail attachments, downloads, exports, rollback).
- Shortcuts and the mouse's back button no longer act behind an open dialog, the command palette or the setup (Ctrl+W closed a tab behind a confirmation).
- A confirmation that cannot be undone starts on „Abbrechen“: Enter no longer deletes for good.
- Closing the command palette gives the focus back to the note or the tree row.
- Enter or Escape that finishes a Japanese, Chinese or Korean input (or a dead key on a Mac) no longer submits a field, renames a page or closes a dialog.
- Escape that closes the slash menu or the find bar no longer ends the focus mode as well.
- „Rückgängig“ of an earlier setting no longer also takes back a later change in the same section.
- During a focus session, messages with „Rückgängig“ show at once instead of waiting until its end.
- Several quick messages no longer push away a recent „Rückgängig“.
- „Rückgängig“ of a deleted open page brings its tab back.
- A new page no longer takes the id of a page emptied from the trash (it opened in that page's view mode).
- The outline shows the headings of the page shown, also in the source view.
- „Rückgängig“ after moving pages always takes back the last move, the one its message names.
- Deleting a row in the page tree keeps the focus in the tree.
- Start setting „Startseite“ or „Tagesnotiz“: the restored tabs are no longer overwritten.
- With „KI verwenden“ off, the page menu no longer offers „Besprechung zusammenfassen“, and Settings → Tastatur no longer lists the assistant shortcuts.
- The English interface no longer shows „Seite/Seiten“ in the tag view and on PDF cards.
- A second question no longer leaves the first one waiting forever (closing the window could get stuck).
- Two quick clicks on the next day in a daily note move two days.
- Calendar event details take the focus when opened with the keyboard and give it back when closed.
- German texts in the English interface: page counts of PDFs and tags, the quick search booking notice.
- Ellipsis without a space in all menu items and progress texts („Board exportieren…“).
- The graph says „1 Seite“ and „1 Verknüpfung“; the briefing tile reads „noch offen, 2 heute insgesamt“.
- A tooltip no longer stays on screen after the view changed under the pointer.
- The empty graph shows its message as one centered block; the intro scene „Zeit“ stays one board in small windows.
- URLs in mono fields no longer show as „http: //“.
- A link to a PDF highlight opened the viewer at the page and then jumped again to the highlight; it now goes straight to the highlight, so a click right after opening lands where it is aimed.
- Light themes: the favorite star and the warning color of budget bars stand out clearly from the page.
- Today's hours count as missing only from the evening on, in the week review, the day review and the week proposal as on the start page: no „noch 8,00 h offen“ next to „Keine Lücken“ during the day, and the week proposal no longer shows „0,00 h fehlen“.
- Start page: a running timer keeps pause and stop under the clock in a narrow „Heute“ card instead of over it; the budget card no longer scrolls sideways and cuts „Überschritten“.
- Split panes: the tab strip no longer shows an empty slot at its left, and the active tab keeps a readable title.
- Kalender: booked time too narrow for its reference shows the hatch only (no „N…“); today's head keeps its icons on one row.

## Checklist for Windows (manual)

- Two computers with Git sync: on A move a page below another page and rename another one, sync; on B sync: the pages are moved and renamed, their versions („Versionen“) and time entries are still there, nothing in the trash.
- On A run „Aufräumen“ with more than ten pages, sync; on B sync, then sync both again: no page exists twice.
- On A delete a page, on B edit the same page and sync B first, then A: the page is back on A with B's text, with the notice „Gelöschte Seite zurückgeholt“.
- A page titled „README“ and a page „Zeiterfassung“ with a subpage: after syncing both computers, B has all three pages with their text.
- Settings sync on: A uses another AI provider than B; after syncing, B's assistant still works with its own provider.
- Start Arcalo twice from the start menu: the second start only brings the window to the front.
- Fresh install with time tracking: after the setup, the timesheet, the start page widget „Zeit diese Woche“ and the week review show no missing hours for the days before the setup; set Friday to 5 h in „Saldo und Urlaub“ and check the start page says 5 h on Friday and nothing on a vacation day.
- Settings → KI & Modelle → „KI verwenden“ off: Settings → Netzwerk shows no AI provider row and no „Testen“ for one.
- Paste a list of 2,000 tasks into a page: the app stays responsive and the tasks view shows them.
- Open a confirmation (page „…“ → „Seite löschen“ on a page with subpages), press Ctrl+W and Ctrl+N: nothing happens behind it; Enter cancels.
- Scroll a long note, open another tab and come back: same position; type, switch, come back, Ctrl+Z undoes the typing.
- With a Japanese IME (Microsoft IME): rename a page in the tree, type a word and confirm the candidate with Enter: the field stays open until the next Enter.
- Press F6 several times: the focus moves ribbon → sidebar → page → side panel; after deleting a page F6 reaches „Rückgängig“.
- With NVDA: type `/` in a note and press ↓: NVDA reads the chosen entry.
- German UI: tooltips of the ribbon and the editor show „Strg“ and „Umschalt“; Settings → Tastatur records and shows combinations with them, and the sidebar shortcut as „Strg+#“ on a German keyboard; tooltips and the hint under the chat write keys as „Strg+Umschalt+D“ and „Umschalt+Eingabe“.
- New workspace in German: the first daily note lands in „Tagesnotizen“; an updated workspace still uses „Journal“.
- Split the window at 1280 px: Aufgaben, Zeiterfassung and a long page have no sideways scrollbar.
- Projekte next to the side panel: the table fits without scrolling.
- Settings → Darstellung „Stunden als 1:30“: start page, reviews and the calendar show clock hours.
- Start a timer and leave Arcalo open for a few minutes: the Task Manager shows Arcalo (and its WebView2 processes) near 0 % CPU; the red dot pulses three times and then stands still; the time in the status bar, the sidebar and the time sheet counts on.
- Open a note of about 200 KB, switch to the Markdown source (Ctrl+Shift+M) and type: no delay per key; the word count in the status bar updates after a short pause.
- Open about 50 notes in tabs and close them all: the memory of Arcalo in the Task Manager falls back within a minute.
- In a note, click a link to a PDF highlight (`[[Datei.pdf#page=2&hl=…]]`): the viewer opens centred on the highlight in one move; clicking the highlight right away opens its menu.
- Window at 1280 px with the side panel: start a timer on the start page: the clock stays whole, pause and stop sit under it; the budget card shows its status under the reference without a sideways scrollbar.
- During the day, with nothing booked today: the week review shows today as „noch 8,00 h offen“ without a warning, the start page shows „Keine Lücken“ and the week proposal no „fehlen“ badge; after 18:00 all three count today as missing.
