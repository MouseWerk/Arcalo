Arcalo 1.16.0

## Improved

- Git sync: a page moved or renamed on one computer (to another parent, by „Aufräumen“, a new title) is moved on the other computer too. It keeps its versions, time entries and links instead of being deleted and created anew, and „Aufräumen“ no longer leaves every moved page twice on both computers.
- Git sync: a page you deleted that another computer edited meanwhile comes back with that edit (from the trash where possible), with a notice.
- A second start of Arcalo on the same data folder now ends with a message also where the usual check does not work (Linux without a session bus).

## Fixed

- Git sync: pages titled „README“ or below a page „Zeiterfassung“ or „attachments“ never reached the other computer and were removed and added again with every sync.
- Git sync: a page moved on one computer and edited on the other kept only one of the two changes.
- Settings sync: the AI provider and model of each tier, the provider and model of the search by meaning and the prices stay on their computer; a second computer without that provider kept getting them and its assistant stopped working.
- Returning to 1.14 after a failed update to 1.16: 1.14 now knows that 1.16 did not start (it is not offered again) and shows that it returned.
- A secret (access token, API key) changed in 1.14 after returning to it is used again by 1.16.
- A first start of 1.15 or later that could not finish taking over the data of 1.14 no longer hides the notes written in between.
- A timer whose start lies in the future (the computer's clock was set back) can be stopped; the booking is kept without a duration to fill in. Daily backups go on when the newest backup carries a date in the future.
- The password-protected copy of the database key and the window position are written safely: a full disk or a crash while saving no longer damages them.
- A pasted image cut short by a power loss is written again the next time it is pasted.
- Attachments named like Windows devices (`CONIN$.txt`, `COM¹.txt`) are renamed when added, as the Markdown export does.

## Checklist for Windows (manual)

- Two computers with Git sync: on A move a page below another page and rename another one, sync; on B sync: the pages are moved and renamed, their versions („Versionen“) and time entries are still there, nothing in the trash.
- On A run „Aufräumen“ with more than ten pages, sync; on B sync, then sync both again: no page exists twice.
- On A delete a page, on B edit the same page and sync B first, then A: the page is back on A with B's text, with the notice „Gelöschte Seite zurückgeholt“.
- A page titled „README“ and a page „Zeiterfassung“ with a subpage: after syncing both computers, B has all three pages with their text.
- Settings sync on: A uses another AI provider than B; after syncing, B's assistant still works with its own provider.
- Start Arcalo twice from the start menu: the second start only brings the window to the front.
