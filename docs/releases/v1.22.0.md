Arcalo 1.22.0

## Improved

- Jira issues open in a window over the app, with everything Jira's page shows: the description as Jira renders it, all details and your own fields, time tracking, subtasks, linked issues, attachments with previews, comments, work log and history. Open it with a click on an issue chip in a note (Ctrl+click still opens Jira), from the issue list, from the start page, the week plan, bookings, quick search, or with „Issue öffnen…“ in the command palette.
- In the issue window you can change the summary, the description and every field Jira lets you edit, move the issue to another status (with the fields that step asks for), write, edit and delete your own comments, log work into your time tracking and take the issue with „Mir zuweisen“. Each change can be undone; if someone changed the issue meanwhile, Arcalo shows both and overwrites nothing.
- Without a connection the issue window shows the last copy, marked „Stand von …“.
- Copying works when the web clipboard refuses: text, formatted text and images go through the system clipboard instead, and a copy that fails says „Kopieren fehlgeschlagen“ instead of doing nothing or showing „Kopiert“.
- Checkboxes on the start page and its small links are easier to hit.
- A dropdown stays open and moves along when the window changes size, also right after choosing a new interface scale.

## Fixed

- Arcalo no longer closes at random while the tray icon updates (the timer, voice commands or the half-minute refresh touched the tray from another thread).
- In a new appointment, a time, title or place typed while Outlook gives the appointment its key is no longer lost, and the appointment's panel opens after „Anlegen“ also on a busy computer.
- Changing the week in the Zeiterfassung switches the header, the totals and the entries together; the previous week's entries no longer show under the new week for a moment.
- Shift+Tab moves backwards in dialogs, menus, dropdowns, the command palette, tables, quick capture and the source editor on Linux, and no longer leaves a dialog.
- The glow on the live meeting dot and the orange ring on the current PDF search hit are gone, focus rings show only when you use the keyboard, and the red in both contrast themes is easier to read.

## Checklist for Windows (manual)

- Open a Jira issue from a chip in a note, from the issue list and with „Issue öffnen…“: all sections show; change a field, comment, log work and undo a change.
- Copy a meeting summary with formatting and an image from a note, and paste both into Word: both arrive.
- With the timer running, open and close the tray menu a few times over some minutes: Arcalo stays open.
- Create an appointment with Outlook running, type an end time right away and press Enter: the end time is saved.
- In the Zeiterfassung, switch weeks quickly back and forth: header, totals and entries always belong to the same week.
- Shift+Tab in a dialog and in the command palette moves backwards and stays inside.
