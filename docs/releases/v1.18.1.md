Arcalo 1.18.1

## Improved

- If Arcalo cannot update itself, it says why and offers the release page instead of a download that fails: on macOS when it was started from Downloads or the disk image without being moved to Applications, or runs from a read-only drive; on Linux when the AppImage's folder is not writable or Arcalo was not started as an AppImage.
- macOS: when Arcalo runs straight from the disk image or from Downloads, it says so at the start and explains how to move it to Applications (otherwise updates, „Bei der Anmeldung starten“ and the `arcalo` command do not work).
- „Installieren und neu starten“ can be cancelled while it downloads; the next click continues where it stopped.
- When a newer version comes out while an update is downloading, it is downloaded right after.
- Linux: the package and the menu entry describe Arcalo properly and list it under Office.
- Git sync: a file changed on two computers at the same time is kept twice, the other computer's version under its name and yours beside it, and both reach every computer; the notice names the second file. This also holds for files only a canvas shows, and for a file you rename or restore from the file trash. Please update every computer to 1.18.1: while one still runs 1.18.0, it removes such a second file from the server again and the next 1.18.1 sync puts it back.

## Fixed

- Windows: Arcalo starts on computers without the Microsoft Visual C++ Redistributable (installer, portable version and Store package), and the installer puts the `arcalo` command on the PATH there as well.
- Windows: cancelling the uninstall at the „Arcalo is running“ question no longer removes the `arcalo` command from the PATH.
- Linux (.deb): installing or removing Arcalo no longer replaces or deletes another program named `annalo`; the package now declares the sound library voice notes need.
- Git sync: a sync whose upload failed, or that was ended after it had fetched changes, no longer undoes the other computer's changes on the next sync; those changes arrive, and a note changed on both sides stays a conflict for you to decide.
- Git sync: a merge with the server that was interrupted no longer overwrites the server's notes with the next sync.
- Git sync: a file only the other computer changed is taken over instead of being uploaded back in its old version.
- Git sync: a linked file (symbolic link) in the repository is never followed, so no file outside the repository can be read or uploaded through it.
- A full disk during an update download now says „Nicht genug freier Speicherplatz“; the download continues once there is room.
- An update file that was changed or deleted after its download is downloaded again instead of failing at every quit.
- An interrupted update download that a server or proxy resumed at the wrong place is started again instead of failing its check.
- macOS: an update installs also when Arcalo is on an external drive.
- An update feed with an entry for a platform Arcalo does not know no longer stops updates for all platforms.
- Settings from Arcalo 1.14 and 1.18.0 are taken over exactly once on the update.

## Checklist for Windows (manual)

- On a fresh Windows 10/11 without the Visual C++ Redistributable (Apps & features: no „Microsoft Visual C++ 2015-2022“): install, start, and run `arcalo --version | Out-String` in a new terminal. Do the same with the portable ZIP.
- Uninstall while Arcalo is running and press Cancel at the question: Arcalo stays installed and `arcalo --version | Out-String` still works in a new terminal. Uninstall again and confirm: the program folder is gone from the user PATH.
- Apps & features: the Arcalo entry links to arcalo.mousewerk.de.
- On a machine without WebView2: the installer adds it, also behind a proxy.
- Update 1.18.0 → 1.18.1 with the default mode: the background download, „Jetzt neu starten“, the app restarts on 1.18.1 with „Arcalo wurde auf Version 1.18.1 aktualisiert“.
- Mode „nur benachrichtigen“: „Installieren und neu starten“, then „Abbrechen“ during the download (no error), click again (it continues), then install.
- Quit Arcalo while `arcalo pages list` runs in a terminal: the update installs; the command either finished or ended without changing data.
- Portable ZIP: an update offers „Neue Version herunterladen“ and installs nothing.
- Git sync with two computers on 1.18.1: change the same drawing on both, sync both twice: both versions are on both computers and on the server, the notice names the second file, the notes are unchanged.
