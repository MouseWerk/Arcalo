Arcalo 1.19.0

## Improved

- The open page is shown in the file tree: its folders open and the tree scrolls to it, also for a page in the split pane; pages shown in the other pane are marked. „Im Baum zeigen“ (Ctrl+Shift+R) brings it into view at any time.
- New folders start collapsed, and folders opened only to show a page close again when you open another one. The open folders are remembered per workspace.
- The page filter highlights what matched, finds paths such as „Kunde/Angebot“ and similar titles, and opens the first hit with Enter.
- Several selected pages can be added to the favorites, colored, tagged, duplicated, exported as one HTML file, moved and deleted at once; every action takes all selected pages, also subpages of a selected folder.
- Drag a page into a note to insert a link to it, onto a pane to open it there, or onto the empty area below the tree to move it to the top level.
- „Neu“ in the file tree creates pages, folders, canvases, drawings, tables and pages from a template, in the folder you right-clicked or at the top level.
- Typing letters in the file tree jumps to the next page starting with them; folders show how many pages they hold; long titles show their full name on hover.
- „Symbol ändern…“ opens a compact icon picker instead of a long submenu, and starred pages are called „Favoriten“ everywhere.
- The file tree, the smart folders, the favorites and the tags are easier to use with the keyboard and screen readers.
- Switching a page to the Markdown source view and back is faster (a 5,000-line note: about 0.4 s instead of 1.1 s) and keeps undo history, cursor and scroll position; edits made in the source view are one undo step.
- Jira: syncs and the issue list load less; an issue's description and comments are loaded when you open it (or hover its key) and are then kept for offline use.
- Zeiterfassung: today's column in the week overview is marked with a quiet gray tint and a bold head instead of the accent color.
- Windows: the installer carries the WebView2 setup itself, so a computer without WebView2 gets it also behind a proxy (the installer is about 2 MB larger).
- An update waits for `arcalo` commands that are running in a terminal and says so in the window; it never ends them. After two minutes it installs beside the command on macOS and Linux; on Windows it installs the next time you quit. If a command keeps an update back three times, Arcalo names it at the next start.
- The notice after the old Annalo folders were removed now reads „Speicherplatz freigegeben“.

## Fixed

- „Nach oben/unten“, „Eine Ebene höher“, „Auf die oberste Ebene“ and drops between pages can be undone, and „Rückgängig“ after moving several pages restores their order; a drop that moves nothing no longer replaces the undo of the previous move or „Aufräumen“.
- In folders sorted by name or date, „Nach oben/unten“ and drops between pages now say why they do nothing.
- Clicking Tagesnotizen, a year or a month opens and closes it instead of an empty page.
- The bar for several selected pages no longer covers or shifts the tree, and its count is readable at 900 px; the open page and the selected pages look different, also in the contrast themes.
- „Tag hinzufügen“ for a selection never breaks a hand-written tags list: comments are kept, and pages it cannot change safely are left as they are and named.
- The sidebar is wider in small windows; hover buttons no longer squeeze titles; renaming deep pages has a wider field.
- Git sync: different line ends alone are never a conflict, and notes from Windows computers are stored with normal line ends. Notes that Arcalo 1.18.0 took over on Windows with Windows line ends get normal line ends once; the text before is kept under „Versionen“.
- F5, Ctrl+R and Ctrl+Shift+R no longer reload the app (for example behind a dialog or in the palette).
- Quitting while an update waits for a terminal command stores what you typed meanwhile before installing; a second quit no longer cuts the install off.
- The window no longer freezes when time tracking is switched off (or the app lock is on) and a setting is saved at the moment the tray icon refreshes.
- Assistant: after changing any setting, the next question to a model without tool support no longer waits for the server's cooldown again.

## Checklist for Windows (manual)

- On a Windows 10 without WebView2 (Apps & features: no „Microsoft Edge WebView2 Runtime“), behind a proxy if at hand: install with the setup; WebView2 is added without a separate download prompt and Arcalo starts. The Microsoft Store build still starts and needs no WebView2 setup.
- With an update ready, run a long `arcalo` command in a terminal (e.g. `arcalo pages create Test --stdin`, leave it waiting), then quit Arcalo: the window says „Das Update wartet auf einen Terminal-Befehl“. End the command (Ctrl+Z, Enter): the update installs and Arcalo restarts on the new version. With the command still running after two minutes, Arcalo says the update installs at the next quit and the command keeps running.
- Ctrl+Shift+R and F5 with a dialog open, in the setup and in the palette: no reload; Ctrl+Shift+R in the editor shows the open page in the tree.
- Open a deeply nested page from the search, a link and a split pane: the tree scrolls to it. Select several pages with Ctrl+click and use each action in the selection bar; undo a move with „Rückgängig“.
- Drag a page into a note, onto the other pane and onto the empty area below the tree. Create each kind from „Neu“ in the toolbar, the right-click menu and the empty tree area.
- Check the tree at 900 px and in the contrast themes: selection vs open page, drop markers, hover buttons.
- A workspace synced by 1.18.0 on Windows: after the update a note shows a version from the update under „Versionen“, the next Git sync uploads the line-end change once, and a second start changes nothing.
- Zeiterfassung week overview in light, dark and both high-contrast themes: today's column is tinted and its head bold. Jira: open an issue (the description loads), open it again offline (still shown).
