Annalo 1.4.0

## Fixed

- **Git sync on a second computer no longer deletes notes**: the first sync of a new installation merges with what the server has. The server keeps every note; notes only the server has appear as pages here (with their folders), a note that exists on both sides with different text becomes a conflict to merge.
- **Git sync only sends a complete Markdown copy**: a missing mirror folder (USB or network drive not connected) or a wrongly chosen folder with other files is refused with a clear message in the settings and the developer log, instead of deleting everything on the server or uploading the folder's files. Refreshing the copy and syncing never run at the same time, and a sync only runs on a copy that was really refreshed.
- **Safety stop for mass deletions**: a sync that would delete more than 10 notes on the server (or more than a fifth of them) stops and asks: Einstellungen → Sicherung „Löschungen übertragen“. When the server deletes many notes at once, they stay here and are uploaded again.
- **Stale Git locks**: a sync that was interrupted (timeout, crash) no longer blocks every later sync; clearer messages for connection, login and disk problems.
- **Private pages stay local**: a page tagged private in its front matter (`tags: [privat]`) is recognized when it is open in the assistant, and search results, tasks and the activity log of private pages keep the conversation on the local model. Embeddings skip every paragraph of a private page.
- **No crashes on unusual text**: pasted links whose page title contains umlauts at certain positions, provider addresses ending in special characters, damaged certificate files, `file://` links with special characters and oversized tool answers from an AI server no longer close the app.
- **Page titles keep their links**: `[ ] | # ^` in a title are replaced (brackets by parentheses, the others by look-alike characters), the title field shows the rule while typing. Renaming no longer changes links inside code.
- **Linked files**: files linked as `[[Angebot.pdf]]` or `[Angebot](Angebot.pdf)` count as used, are renamed with the file, and are included in the Markdown export, the Markdown copy and the Git sync.
- **Time entries**: exported bookings cannot be deleted (the menu says why), a running one is stopped first. `/zeit 2h` shortly after midnight books on today; a time skipped by the summer time change is taken an hour later. A focus session keeps a booking you corrected by hand. A timer forgotten over night is reported the next morning, booking more than 12 hours asks first, and such an entry stays editable.
- **Moving the data folder** takes the file trash, the logs and the Git sync along.
- **AI costs**: indexing for the semantic search counts toward the monthly cost limit.
- **Assistant tools**: the read-only Git tool never runs programs configured in a repository; PowerShell and Git tools stop after two minutes.
- **Vault import**: runs in the background with progress and „Abbrechen“; notes from old Windows editors keep their umlauts; very large notes are shortened with a note; two different files of the same name (in different folders, or already in Annalo) are both kept.
- **Saving on a full disk**: a save that fails at the last step no longer leaves later changes unsaved without notice.
- **Start-up problems**: a damaged database, one from a newer Annalo version or a data folder that cannot be written now show a dialog (restore the last backup, open the folder, quit) instead of closing without a window. A wrong value in the settings resets only that setting. A write-protected data folder and invalid network settings are shown as a notice.
- **Clear messages**: error messages are German throughout, without technical prefixes; network errors name the cause (proxy, certificate, answer interrupted). An AI server that does not answer ends with a timeout, a hotel WLAN login page or an empty answer is reported instead of shown as an answer, and an answer cut off midway is marked „unvollständig“.
- **Missing certificate file**: requests fail with the reason instead of going out without the proxy.
- **Secrets on Linux** are written privately and completely; a damaged file is kept.
- **Portable copies** and an installed Annalo can run at the same time.
- **Developer log**: when the log cannot be written, Einstellungen → Protokoll says so.
- Switching between the visual editor and the Markdown source (Ctrl+Shift+M) right after typing shows what you just typed; before, the other editor could show an older state and overwrite the last edit.
- Typing in a dialog (for example the template search) no longer jumps back into the note after the first letter.
- Two panes with the same page, visual or Markdown source, keep the edits of both when you type in them one after the other; the caret no longer jumps when the other pane saves.
- Raw HTML and comments in notes (`<kbd>`, `<details>`, `<div>`, `<!-- Kommentar -->`, text like `a<b und c>d` or `<Kunde>`) stay exactly as written after an edit; they are shown as their source text and edited in the Markdown source.
- Code blocks that contain ``` are saved with a longer fence, so they no longer break apart.
- An empty task `- [ ]` stays a task, and an escaped `\#tag` stays plain text instead of becoming a tag.
- „Als Text einfügen“ after a smart paste no longer removes the text typed just before it.
- Assistant: „Neuer Chat“ while a tool waits for approval no longer blocks the panel, „Stoppen“ also ends tool calls, and a reply that arrives after „Neuer Chat“ no longer ends up in the new chat.
- macOS: Option+←/→ jumps by word again; back and forward are ⌘[ and ⌘] (changeable in Settings → Tastatur). Back/forward shortcuts never fire while you type in a text field or a note.
- The time entry dialog books once, also when Enter is pressed twice quickly; Enter while an input method composes a word no longer submits (time entries, assistant, command palette, AI bar, sidebar search).
- A note whose save failed stops retrying once its tab is closed, and reports the error once instead of every five seconds.
- Ctrl+F and Ctrl+H only open the note search when you are not typing somewhere else (a dialog, the command palette, the assistant).
- A slow page-tree refresh can no longer close tabs of pages that were just created.
- Assistant: a fast answer no longer appears twice, and very long answers are shown shortened (copying and „Als neue Seite speichern“ still take all of it) instead of freezing the window.
- A damaged drawing, or one in a format Annalo does not know, opens with a notice instead of an empty canvas, and is never overwritten; „Neu beginnen“ keeps a copy as `.bak`. Drawings in the Markdown form of Obsidian's Excalidraw plugin (also compressed) open with their content.
- Pasting megabytes of text into a note asks whether to attach it as a text file instead, so the note stays fast.
- **Callouts without a title** (`> [!question]` with the text on the next line, as Obsidian writes them) show their type again („Frage“, „Tipp“ …) instead of an empty first line.
- **Code blocks in light themes**: every kind of code (keywords, values, decorators, CSS selectors, headings) has a readable color in every theme, and the block stands out from the page in Solarized, Gruvbox and the other tinted themes. The violet of question and example callouts is readable in light themes too.
- **„Symbol ändern“ in the file tree**: the icon names are German, and the long list scrolls inside the window instead of running off the screen. Long menus scroll everywhere, the keyboard selection stays in view.
- **Table view**: the page icon keeps its size and titles use the whole cell; „Öffnen“ appears over the end of the title on hover instead of taking room from it.
- **Word count in the status bar** is right in the Markdown source mode (it counts as you type, without the properties) and in split view (it follows the pane you work in).
- **Presentations** show `[TOC]` as the list of the other slides, footnotes as numbers with their text at the foot of the slide, `==highlights==` highlighted and `<!-- spalten -->` blocks as columns, instead of the raw Markdown.
- **Presenter view**: the current slide keeps the 16:9 shape of the projector instead of a nearly square box.
- **„Beamer“ look in a dark theme**: callout text, code, links and highlights on the white slides are dark and readable.
- **Tabs** are as wide as their title (up to a maximum) instead of being cut while the tab bar has room; when it gets tight, short titles stay whole and only long ones are shortened.
- **Markdown source mode** shows every character as typed (no `->` or `!=` turned into arrows or symbols).
- **Board cards**: the page icon sits on the first line of a long title, and number and checkbox properties show their name („aufwand 8“).
- **Time tracking in a narrow pane**: the four totals are shown two by two instead of three and one.
- **Menus and suggestion lists that scroll** have the same space on both sides.
- **Screen readers** announce task checkboxes in German („Aufgabe: …“).
- **Disclosure rows** („Weitere Modelle“, error details in the assistant) use Annalo's chevron instead of the browser's triangle; badges keep a gap between icon and text.
- **„Anbieter hinzufügen“**: every provider has an icon (this computer, cloud service, own server).
- **Drawings without a preview** (made in another app or before previews existed) are no longer labeled „Leere Zeichnung“.
- **Theme colors**: the text selection follows the accent color, the info color of Annalo Hell is readable on white, and the recording dot and activity colors follow the theme.
