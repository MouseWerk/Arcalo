B) Linux Secret Service (keyring sync-secret-service, fallback to 0600 file only without a Secret Service, migrate existing secrets.json) + structured logging (tracing + tracing-appender, levels, JSON lines option, spans with timings for sync/AI/DB, keep redaction) + notification actions (Windows toast buttons Snooze/Open/Done with activation back into the app; macOS/Linux equivalents where possible) for reminders, tasks, briefing, focus.

D) Git sync sign-in: "Sign in with GitHub/GitLab" (OAuth device flow; GitLab self-hosted URL), token stored in credential store, refresh; plus "Use system Git Credential Manager" option; keep PAT as advanced.
Then quality audit + full e2e + release + website.

Multiple named proxy profiles (e.g. "Firma", "Direkt", "VPN"). Settings UI: Network section with profiles + a per-service table, "test connection" per service, effective-route preview; policies (admin can lock per service). Replace the single global "accept invalid certificates" switch with per-host trust. Logs show which route a request used (redacted).
Decision: 1.10 stays a separate release (not folded into 2.0).
